to think.
**Say the structural fact out loud:** choose #505 and the Unit 4.3 capstone **is** the entry.

## 4. Middle School CS: Work day

### Slide 1: Today

> Create one work slide for a middle school computer science class titled "Work Day." Leave a large open
> area for the teacher to list what is due. Add a box at the bottom with the four things that go wrong
> with lists: always off by one, you used 1 for the first item and the first is 0; crashes partway
> through, you went to length instead of length minus 1; only one item ever comes out, you used a fixed
> number where the index belongs; nothing happens, the list is empty. One slide.

### Board version

```
WORK DAY

  the index isn't WHICH ONE. it's HOW FAR FROM THE START.
  first item = 0
  for index from 0 to (length of list) - 1

IF IT BREAKS
  always off by one  -> you used 1 for the first item
  crashes partway    -> you went to length, not length - 1
  only one item      -> fixed number where index belongs
  nothing happens    -> the list is empty
```
