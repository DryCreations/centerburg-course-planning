### Slides

- **Slide 2, Standards + Today:** "Today: LOOPS, code that repeats. Not on Friday's quiz. Friday's quiz only covers if statements and everything before."
- **Slide 3, Repeat vs forever:** "`repeat 4 times`: runs the blocks inside exactly 4 times, then stops. `forever`: keeps running the blocks inside for as long as the game runs."
