# Grading Categories and Weights (PowerTeacher + Google Classroom)

Set up **identical** grade categories in **PowerTeacher Pro** and **Google Classroom** for each class so grades
sync correctly. Source of truth: the course syllabi in `first-two-weeks/<course>/syllabus/syllabus-draft.md`.

## How to make sync work (read first)

- **Category names must match exactly** between PowerTeacher and Google Classroom (same spelling, same
  capitalization). Type them from this doc, do not improvise.
- **Set the same weight** on the category in both systems. In Google Classroom: Settings, "Grade calculation,"
  set **Overall grade calculation = Weighted by category**, then add each category with its weight. In
  PowerTeacher Pro: set the class to **weight by category** and enter the same categories and weights.
- **Weights total 100% in every class** (checked below).
- The **50% floor** ("quarter grades not recorded below 50%") and the **late-work policy** are grading settings,
  not categories. Handle those in PowerTeacher, not as a category.
- Create categories **before** you post assignments so each assignment lands in the right bucket and syncs.

| Category | Weight |
|----------|-------:|
| Production and Deadlines | 40% |
| Coverage | 25% |
| Craft | 20% |
| Staff Contribution | 15% |

**In it:** Production and Deadlines = one grade per assigned spread or page, production tasks, weekly Friday
status. Coverage = one coverage grade per quarter plus each event submission. Craft = a photo grade and a
caption grade each quarter, plus design on each spread. Staff Contribution = one staff work score per week plus
role duties. (No state exam in this class.)

## Quick setup checklist (per class)

- [ ] PowerTeacher Pro: set class to **weight by category**, add the categories and weights above.
- [ ] Google Classroom: Settings, **Weighted by category**, add the same category names and weights.
- [ ] Names match exactly in both systems.
- [ ] Weights total 100%.
- [ ] 50% floor and late policy set in PowerTeacher.
- [ ] Post assignments into the matching category.
