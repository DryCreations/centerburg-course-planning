# Centerburg High School - CTE Program Planning

## Overview

This workspace contains course standards, planning materials, and resources for the Career & Technical Education (CTE) programs at Centerburg High School.

## Courses

### CTE Courses (Information Technology Career Field - Interactive Media Pathway)
- **Design Techniques** (145095) — Photo editing, digital imaging, graphics
- **Video and Sound** (145110) — Video/audio production, editing, distribution
- **3D Techniques** (145120) — 3D assets, interactive media, programming *(not offered this year — low enrollment; Hard Surface Modeling planned for next year)*

### CTE Course (Transportation Technologies Career Field)
- **Aviation Unmanned Aircraft Systems** (177024) — UAS operations, regulations, GIS

### Non-CTE Courses
- **Yearbook** — School yearbook production
- **Middle School Computer Science** — Grades 7–8, year long; aligned to Ohio K–12 CS Standards
- **Applications of Robotics** — Second semester only; not part of the IT pathway
