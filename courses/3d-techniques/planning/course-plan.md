## Course Overview

**School Course Name:** Intro to Technical Drawing & 3D Design

Students will learn to communicate about and create in 3D space — starting with hands-on technical drawing, orthographic views, and a real client design project (a printed hall pass for a teacher at the school) using TinkerCAD. After completing the print, students move fully into Blender for polygonal modeling, hard surface techniques, UV mapping, animation, and rendering for the remainder of the year.

This course is the foundation year for the [Hard Surface Modeling (145140)](../../program/pathway-course-structure.md) transition. Skills built here — 3D spatial vocabulary, design iteration, polygonal mesh work, UV surfacing, and animation — transfer directly into the HSM curriculum. See the [HSM Transition Pathway](#hsm-transition-pathway) section below.

Programming (Strand 5) is covered at a conceptual literacy level — students read and annotate scripts, trace logic, and understand SDLC and version control concepts. Students who want to write Blender Python do so as an extension track. WebXam performance on Strand 5 is not the instructional priority this year; this course runs once before the program transitions to Hard Surface Modeling (145140).

## BPA Competition Integration

See the [BPA competition planning document](../../../program/bpa/competition-planning.md) for the full season calendar, national deadlines, and how to run a local competition.

### Course Alignment

This course is focused on 3D modeling, hard surface techniques, and animation — the BPA events that directly reward those skills are **Computer Modeling (#425)** and **Computer Animation Team (#440)**, both Secondary-only events. Programming is covered for WebXam requirements but is not a BPA competition track for this course. See [bpa-events.md](bpa-events.md) for the full per-course reference.

### Recommended Events

Students select **one primary event** and one backup.

| Event # | Event Name | Format | Standards Aligned | Notes |
|---|---|---|---|---|
| **425** | Computer Modeling | Individual | Strand 7.6 (3D Modeling / Animation) | Concept → profile → prototype → final model/scene. **Secondary-only event.** Strongest direct alignment. |
| **440** | Computer Animation Team | Team (up to 3) | Strand 7.6 (Animation) | Computer-generated animation ≤2 min. **Secondary-only event.** |
| **V11** | 2D Animation Team | Team (Virtual) | Strand 7.6 (Animation) | 1:30–2:30 min 2D animation. **National-only virtual event** — register Dec 1, submit Jan 15. |
| **391** | IT Concepts — Open | Objective Test | Strand 2 | General IT knowledge test. Good backup/lowest-barrier option. |

### Local Competition (January)

Run a school-level showcase before the state conference:
- Students present their model, animation, or rendered scene to a judging panel
- Invite BAC members from relevant industries (product design, architecture, game development, engineering, 3D fabrication/printing) as judges
- Use the WSAP Computer Modeling or Computer Animation scoring rubric
- Top performers advance to state; all students receive written feedback

## Prerequisites

From the Ohio CTE course description: *"It is strongly recommended that students have experience with programming and hard surface modeling before taking this course."*

In practice, this course is the **starting point** for students in this program — it is not designed to require prior coding or 3D experience. The school's offering is titled "Technical Drawing and 3D Printing," which reflects the entry-level framing. OnShape and Blender are introduced from the ground up.

## HSM Transition Pathway

This course (145120 — 3D Techniques) is the planned foundation year before the program transitions to Hard Surface Modeling (145140). The table below maps what transfers and what is new so that Year 2 planning is clear.

| Category | 145120 This Year | 145140 Next Year |
|---|---|---|
| **Strand 5 Programming** | ~26% of WebXam; taught via Blender Python | **Absent entirely** — no programming on HSM WebXam |
| **7.6 Animation** | 19.54% of WebXam | **34.12%** — single largest outcome |
| **2.13 Rollout & Handoff** | Not on 145120 WebXam | **7.06%** — previewed via capstone delivery package |
| **2.14 Artificial Intelligence** | Not on 145120 WebXam | 2.35% — AI tools for 3D workflows |
| **2.9 Project Concept Proposal** | Not on 145120 WebXam | 2.35% — proposal format introduced this year anyway |
| **7.4 Graphics** | 12.64% — fully covered | Same strand; skills transfer directly |
| **7.3 Production** | 10.34% — fully covered | Same strand; pipeline framing transfers |
| **OnShape modeling mindset** | Constraint-based technical drawing | Precision mesh work and surfacing in HSM |
| **Blender polygonal modeling** | Box modeling, subdivision, materials | Directly teaches to HSM 7.6 + polygonal modeling objectives |

**This year\'s Unit 4.2 Capstone intentionally previews HSM workflows:** concept sketch → technical drawing → 3D model → render/print → presentation delivery. This is the 2.13 Rollout & Handoff pipeline students will formally assess in HSM next year.
