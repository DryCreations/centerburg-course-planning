# 3D Techniques — BPA Competition Reference

**Course:** 145120 3D Techniques
**Focus:** 3D modeling, hard surface modeling, technical drawing, and 3D printing
**See also:** [Master BPA Events Reference](../../../program/bpa/bpa-events-master.md)

> **Cross-course note:** Students may compete in any BPA event. Events below are the strongest fits for 3D Techniques content. This course focuses on 3D modeling, animation, and technical design — not programming. Students interested in programming or development events should look at the master reference or speak with the advisor.

---

## Competition Pathway

```
School Competition (January)  →  Ohio State Conference (Feb/Mar)  →  NLC Nashville (May 6–10)
Virtual Events: skip qualifying entirely — register Dec 1, submit Jan 15
```

Advancing at each stage is the student's choice. See the [master document](../../../program/bpa/bpa-events-master.md) for full dates and details.

## Primary Events for 3D Techniques Students

### #425 Computer Modeling *(Recommended primary event — Secondary only)*

| | |
|---|---|
| **Format** | Individual |
| **Deliverable** | Full submission package: research → profile → concept design(s) → prototype(s) → final model and/or scene |
| **Division** | Secondary only (not available at post-secondary) |
| **BPA Topic** | Scenario or prompt assigned each year by WSAP |
| **Class Connection** | Unit 1.2 (3D Graphics/Modeling Sampler — early prototype), Unit 2.1 (Animation/Production), Unit 2.2 (BPA project production phase) |
| **BPA vs. Class** | Class projects build the skills and output incrementally across units. By Unit 2.2, students doing the BPA option are producing toward the WSAP scenario. Both class and BPA students use the same modeling tools and workflow. |
| **Why it fits** | This is the only BPA event that specifically rewards 3D modeling, hard surface design, and scene creation. It is the clearest path from this course to a BPA competition entry. The research → profile → prototype → final workflow mirrors the design process taught throughout the course. |

---

### #440 Computer Animation Team *(Team option — Secondary only)*

| | |
|---|---|
| **Format** | Team (up to 3) |
| **Deliverable** | Computer-generated animation, not to exceed 2 minutes, on the assigned topic |
| **Division** | Secondary only |
| **Class Connection** | Unit 2.1 (Animation Sequence project) and Unit 2.2 (BPA project production phase — animation track) |
| **BPA vs. Class** | The animation sequence from Unit 2.1 is the foundation. BPA teams extend and polish this into a full narrative/themed 2-minute piece. Requires outside-class refinement. |
| **Why it fits** | Computer animation is a direct outcome (7.6) in this course — the highest-weighted EOC outcome. 440 is the competitive expression of those skills. |

## Not Recommended for This Course

Programming-based events (#330 C#, #355 Python, #390 Computer Programming Concepts, V03 Software Engineering) are not recommended for students in this course. While the course touches on programming concepts to meet WebXam requirements, it is not a programming course. Students whose primary interest is programming should see the master reference or talk to the advisor about other options.
