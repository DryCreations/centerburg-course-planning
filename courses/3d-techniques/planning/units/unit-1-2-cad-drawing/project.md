# Project: Blueprint to Print

**Course:** 3D Techniques (145120)
**Unit:** 1.2 — Technical Drawing & CAD Foundations
**Duration:** Weeks 3–4 (2 weeks; lab work feeds directly into this project)

---

## Overview

Given a teacher-provided schematic drawing, model the part completely in OnShape, export and slice for 3D printing, physically print the object, and compare the result to the original blueprint in a one-page design reflection. This is the first full production cycle of the course: design intent → digital model → physical artifact → evaluation.

---

## Class Prompt: Blueprint to Print

### What You're Building

Your teacher will provide a schematic drawing of a mechanical part — a bracket, a housing, a fixture, or a functional object — with complete dimensions, tolerances, and multi-view orthographic drawings.

Your job: make it exact, print it, and analyze the result.

### Deliverables

## Design Reflection Requirements

Your one-page reflection must address:

1. **What I modeled:** Brief description of the part and its intended function (2–3 sentences)
2. **Slicer settings chosen:** Layer height, infill %, supports — and *why* you chose each value
3. **Dimensional comparison:** Measure at least 3 critical dimensions on the printed part. Compare to blueprint specs. Use this table:

| Dimension | Blueprint Spec | Measured Result | Discrepancy | Likely Cause |
|-----------|---------------|----------------|-------------|-------------|
| | | | | |
| | | | | |
| | | | | |

4. **What worked:** One thing about your model or print that you're satisfied with.
5. **What I'd change:** One design decision or print setting you would change, and why.
6. **Career connection:** Name one real industry where reading technical drawings like this one is a daily job requirement.

## Requirements Checklist

### Modeling
- [ ] OnShape model matches all blueprint dimensions (within ±0.5 mm as modeled)
- [ ] All features from the blueprint applied: extrude, cutouts, fillets/chamfers, shell (as required)
- [ ] Model is fully constrained (no under-constrained sketch)
- [ ] Slicer settings documented (screenshot + settings notes)

### 3D Print
- [ ] Part physically printed
- [ ] Print completed without catastrophic failure (minor imperfections expected and acceptable)

### Reflection
- [ ] Dimensional comparison table filled in (3+ measurements)
- [ ] All 6 reflection sections answered
- [ ] One page (at least 200 words)
