## Student Overview

### What Is This Unit About?

Before 3D printers and digital models, engineers communicated in 2D: orthographic projections, cross-sections, and technical drawings with precise dimensions. This unit teaches you to read and create those drawings AND to model the same object in OnShape using parametric CAD tools. You will produce a complete technical drawing set and a 3D model for a real printable object.

### What You'll Be Able to Do

By the end of this unit you will be able to:

- Create an orthographic projection (front, side, top) with correct dimensions, views, and title block
- Use OnShape Sketch tools (line, circle, arc, dimension, constraint) to create a precise 2D sketch
- Extrude, revolve, and fillet a 3D part in OnShape
- Export a model as an STL file for 3D printing

### Common Issues & Responses

- **Sketch has unconstrained elements (red/yellow lines):** Do not extrude until fully constrained. Require a screenshot showing a fully blue sketch.
- **STL has errors in slicer:** Run through a slicer preview before submission. Most issues are non-manifold geometry — teach how to find and fix.
- **Technical drawing missing a view:** Front, top, and side are all required. A single isometric view does not substitute.

### Differentiation Notes

- **Students who need more support:** Provide a completed technical drawing example with all labels; students replicate the style for their own object.
- **Students who finish early:** Extension in project.md — add a second part and create a simple 2-part assembly in OnShape.

### Assessment Notes

- Project uses the 1–4 look-for rubric. Walk the room during the extrusion sessions — catch unconstrained sketches before they become submission problems.

### BPA Connections

**BPA V25 3D Modeling:** Technical drawing + OnShape model is the foundation of the V25 competition entry. Process documentation (drawing → CAD → print) is required.
