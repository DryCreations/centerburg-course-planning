## Terms

| Term | Definition | Related Standard | DOK |
|------|-----------|-----------------|-----|
| **Constraint** | A rule applied to a sketch that fixes relationships — such as two lines being equal length, perpendicular, or locked to a specific dimension | 7.6.9 | 1 |
| **Sketch (CAD)** | A 2D drawing of a profile shape that will be used as the basis for a 3D operation (like extrude or revolve) | 7.6.9 | 1 |
| **Extrude** | A modeling operation that pushes a 2D sketch profile into a third dimension to create a solid 3D shape | 7.6.9 | 1 |
| **Boolean operation** | A method of combining or cutting 3D shapes using set logic: Union (combine), Subtract (remove), Intersect (keep overlap) | 7.6.9 | 2 |
| **Fillet** | A curved transition that rounds a sharp corner between two surfaces | 7.6.9 | 1 |
| **Chamfer** | An angled cut or bevel applied to a corner or edge, creating a flat angled surface instead of a sharp edge | 7.6.9 | 1 |
| **Shell** | A CAD operation that hollows out a solid, leaving walls of a specified thickness | 7.6.9 | 2 |
| **Assembly** | A CAD file that brings together multiple individual parts and defines how they relate to each other using mates | 7.6.5 | 2 |
| **Mate** | A constraint in an assembly that defines the geometric relationship between two parts (e.g., flush, concentric, coincident) | 7.6.5 | 2 |
| **STL (Stereolithography)** | A file format that represents a 3D surface as a mesh of triangles; the universal format for 3D printing | 2.4.4 | 1 |
| **G-code** | Machine instructions generated by slicer software that tell a 3D printer exactly how to move and extrude material layer by layer | 2.4.4 | 2 |
| **FDM (Fused Deposition Modeling)** | The most common 3D printing method: a heated nozzle melts plastic filament and deposits it layer by layer | 2.4.4 | 1 |
| **Layer height** | The thickness of each deposited layer in an FDM print; smaller layer height = higher resolution but longer print time | 2.4.4 | 2 |
| **Tolerance** | The acceptable range of variation in a dimension — a part spec of 10 mm ± 0.1 mm allows sizes between 9.9 and 10.1 mm | 7.6.9 | 2 |
| **Orthographic projection** | A method of representing a 3D object using multiple 2D views (front, side, top) on a flat plane | 7.4.2 | 2 |
| **Isometric view** | A type of pictorial drawing that shows three faces of an object simultaneously at 30° angles, giving a 3D appearance without perspective distortion | 7.4.2 | 2 |
| **Blueprint / Working drawing** | A technical document containing all the dimensions, tolerances, views, and notes needed to manufacture a part | 7.4.3 | 1 |
| **NURBS (Non-Uniform Rational B-Splines)** | A mathematical method of representing smooth curves and surfaces used in CAD — OnShape uses NURBS geometry under the hood | 7.6.10 | 2 |
| **Vector graphic** | An image made of mathematical curves and shapes (not pixels) — scales to any size without quality loss | 7.4.5 | 1 |
| **Raster graphic** | An image made of a fixed grid of pixels — enlarging it causes it to lose sharpness | 7.4.5 | 1 |

## Key Distinctions

| Term 1 | Term 2 | Key Difference |
|--------|--------|---------------|
| Fillet | Chamfer | Fillet = curved round; Chamfer = angled flat cut |
| Boolean Union | Boolean Subtract | Union combines two shapes into one; Subtract removes one shape from another |
| STL file | BLEND file | STL describes surface geometry only (for printing); BLEND file stores full scene data (materials, rigs, animation) |
| Tolerance | Dimension | Dimension is the exact target measurement; tolerance is the allowed range around that target |
| NURBS | Polygon mesh | NURBS uses smooth mathematical curves (CAD); polygon mesh uses connected flat faces (Blender/gaming) |

## Bell Ringer Prompts

1. What is a constraint in CAD, and why does "fully constrained" matter before extruding?
2. You have a square tube shape. Which two operations could you use: extrude or shell? When would you choose each?
3. What is the difference between a fillet and a chamfer? Draw and label both.
4. If a part dimension is 25 mm ± 0.5 mm, what is the maximum and minimum acceptable printed size?
5. A designer saves a Blender file as STL to share with a client. What information is lost in that conversion?
