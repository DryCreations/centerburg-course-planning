## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | WSAP = Written Student Action Plan — the official BPA event scenario document |
| 2 | C | #440 Computer Animation Team = team animation event (up to 3 members) |
| 3 | B | Storyboard = pre-production visual sequence plan |
| 4 | B | Navigational structure = user flow through an interactive project |
| 5 | C | December 1 = virtual event registration deadline (V11 2D Animation Team) |
| 6 | B | Design brief contains scope, audience, goals, constraints, deliverables |
| 7 | C | Client persona = profile of the target audience |
| 8 | D | Both #440 (live team animation) and V11 (virtual team 2D animation) are team events; student should review both WSAPs to choose |
| 9 | C | Storyboard notes coordinate the whole team + timing; vague boards cause production misalignment |
| 10 | B | License verification is required — "free" does not mean unrestricted; competition context may change what's allowed |
