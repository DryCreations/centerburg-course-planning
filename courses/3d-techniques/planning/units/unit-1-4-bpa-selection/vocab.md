# Vocabulary: Multimedia Tools, Pre-Production & BPA

**Course:** 3D Techniques (145120)
**Unit:** 1.4 — Multimedia Tools, BPA Showcase & Event Selection
**Weeks:** 8–9

---

## Terms

| Term | Definition | Related Standard | DOK |
|------|-----------|-----------------|-----|
| **WSAP** | Written Student Action Plan — the official event prompt document published by BPA each year that describes the competition topic, deliverables, and rubric | 1.1.4 | 1 |
| **Pre-production** | The planning phase before any digital production begins — includes storyboards, design briefs, wireframes, flowcharts, and production schedules | 7.2.1 | 1 |
| **Storyboard** | A sequence of drawn or rough panels showing the planned visual sequence of an animation, video, or interactive project | 7.6.1 | 1 |
| **Wireframe (UI/UX)** | A low-fidelity layout diagram showing the structure and arrangement of a screen, webpage, or interactive presentation | 7.2.1 | 1 |
| **Production schedule** | A timeline document listing every major task, deadline, and responsible team member for a project | 7.2.9 | 2 |
| **Design brief** | A short professional document that defines the project scope, audience, goals, constraints, and deliverables | 7.2.10 | 2 |
| **Client persona** | A fictional but research-based profile of a target user or audience member — used to guide design decisions | 7.2.11 | 2 |
| **Elevator pitch** | A 30–60 second spoken summary of a project, idea, or portfolio capable of being delivered at any moment | 1.1.5 | 2 |
| **Navigational structure** | The plan for how a user moves through an interactive project — menus, links, categories, flow | 7.2.1 | 2 |
| **Interactive element** | A feature that responds to user input — buttons, hover effects, clickable hotspots, sliders | 7.2.3 | 1 |
| **Call sheet / Production log** | A daily or weekly record of what work was completed — used in professional studios and BPA portfolio submissions | 7.3.10 | 2 |
| **Virtual event (BPA)** | A BPA competition event that is pre-submitted online before state conference rather than performed live on-site | 1.1.4 | 1 |
| **December 1** | BPA virtual event registration deadline for most Ohio chapters — V11 2D Animation Team | 1.1.4 | 1 |

## Bell Ringer Prompts

1. What is the WSAP? Why is it the first document you read at the start of a BPA project?
2. What is the difference between a storyboard and a wireframe? When would you use each?
3. A production schedule has three tasks with overlapping deadlines. What would you do to resolve the conflict?
4. You have 30 seconds to explain your BPA project to a judge who don't know your topic. What are the 3 things you must say?
5. What is a virtual BPA event, and what is the main deadline you need to plan around?
