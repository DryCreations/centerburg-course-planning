# Project: Capstone — Summative Portfolio Project

**Course:** 3D Techniques (145120)
**Unit:** 4.2 — Capstone Project
**Duration:** Weeks 30–37

---

## Overview

The capstone is the largest, most complex project in the course. It mirrors a professional commission: plan it, build it, document it, get feedback, revise it, and deliver it. The finished work should represent your best professional-quality output from everything you've learned this year.

---

## Class Prompt: Choose Your Track

Select one of three tracks. Your selection should align with your BPA event (if applicable) and your strongest skills. Projects must be ambitious but achieavable in 8 weeks.

---

### Track 1 — Hard Surface / Product Visualization

**Description:** Create a photorealistic 3D render of an original product or mechanical object, styled for professional marketing or portfolio use.

#### Requirements

| Requirement | Minimum |
|-------------|---------|
| Original 3D model | 1+ objects; not a basic primitive; custom topology |
| Reference-based modeling | 5+ reference images used and documented |
| Quad-dominant topology | N-gons cleaned up; clean edge flow |
| Materials | 2+ PBR materials using Principled BSDF nodes |
| Lighting | 3-point or HDRI + accent lights; background / surface |
| Hero render | PNG ≥ 1920×1080; Cycles preferred, Eevee acceptable |
| Additional renders | Minimum 2 alternate angles + 1 wireframe overlay |
| Process documentation | Design brief + reference collection + 1 process note |

#### BPA Connection
This track directly supports **BPA #425 Computer Modeling** (individual) — the model and render deliverables align with WSAP requirements. If competing, submit WSAP-compliant files.

---

### Track 2 — Animated Short (5–15 seconds)

**Description:** Produce a complete short animation — storyboarded, modeled or assembled from existing (Unit 2 and 3) assets, animated with keyframes, and compiled to final video.

#### Requirements

| Requirement | Minimum |
|-------------|---------|
| Storyboard | 8+ panels, submitted with project |
| Shot list | Labeled table of all shots |
| Animation | Minimum 5 seconds at 24fps; at least 3 keyframed objects/cameras |
| Camera movement | At least 1 camera animation (Follow Path or manual keyframes) |
| Materials + lighting | All scene objects have materials; proper lighting for final renders |
| Image sequence render | Full animation rendered as PNG sequence (not direct-to-MP4) |
| Final video | Image sequence compiled in Video Sequencer → MP4 |
| Hero render | Still frame (best frame) PNG ≥ 1920×1080 |
| Process documentation | Design brief + storyboard + 1 process note |

#### BPA Connection
This track supports **BPA #440 3D Animation** and **BPA V11 Virtual Film**. Submit WSAP-compliant files if competing.

---

### Track 3 — 3D-Printed Prototype + Professional Delivery Package

**Description:** Design a functional or representative 3D-printed object using OnShape CAD, print it in the school lab, render it in Blender for portfolio, and assemble a professional delivery package. This track directly previews HSM 145140 (Advanced 3D Manufacturing).

#### Requirements

| Requirement | Minimum |
|-------------|---------|
| Concept sketch | Hand-drawn or digital; labeled dimensions |
| OnShape CAD model | Fully constrained; printable geometry (no open surfaces) |
| STL export | Confirmed printable in slicer software |
| 3D printed prototype | Physical print; labeled in design brief |
| Blender render | Import STL or OBJ into Blender; add materials + lighting; hero render PNG ≥ 1920×1080 |
| Design brief | All 6 fields; describes problem being solved and constraints |
| Reflective note | How does the physical prototype compare to the render? What would you change in the next version? |

Walk the room as students work. Ask students to point to evidence for each standard before scoring.
