## Student Overview

### What Is This Unit About?

The capstone is the most complete 3D project you've ever made. You'll take a concept all the way from research and technical drawing through CAD modeling, Blender artistic finishing, 3D printing, and a final BAC presentation. The finished work is the centerpiece of your production portfolio.

### What You'll Be Able to Do

By the end of this unit you will be able to:

- Develop an original, printable design concept that solves a real problem or achieves a defined aesthetic goal
- Complete a full design pipeline: concept → technical drawing → CAD → Blender → print → presentation
- Print and post-process a finished physical object at professional quality standards
- Assemble a process book and present the complete project to a live panel

### Common Issues & Responses

- **Concept is not printable:** Require brief approval with a feasibility check: wall thickness ≥ 1.2mm, no floating geometry, fits the printer bed.
- **Process book is just screenshots:** Require narrative explanation of decisions at each phase — why this shape? why these settings?
- **Print fails:** Have a recovery protocol — attempt to reprint early; document the failure as part of the process book (this is realistic professional practice).

### Differentiation Notes

- **Students who need more support:** Allow the capstone to use a Thingiverse model as a starting point — student must modify it substantially and document what changed and why.
- **Students who finish early:** Extension in project.md — produce a product photography set (3+ angles) and write a product description for a hypothetical online store listing.

### Assessment Notes

- Project uses the 1–4 look-for rubric across all production standards. Verbal presentation is required. Grading: deliverables + print (55%), process book (15%), portfolio (10%), presentation (20%).
