## Student Overview

### What Is This Unit About?

Blender is the industry-standard free tool for artistic 3D modeling, animation, and rendering. This unit introduces the Blender interface, core modeling workflows (Object Mode vs. Edit Mode), materials, and basic rendering. You will produce your first complete Blender model — a recognizable object with applied materials and a rendered image.

### What You'll Be Able to Do

By the end of this unit you will be able to:

- Navigate the Blender interface (viewport navigation, editor types, properties panels)
- Use Edit Mode tools: vertex/edge/face select, extrude, loop cut, bevel, inset
- Apply materials with color, roughness, and basic texture settings
- Set up a 3-point lighting scene in Blender and render a final image

### Common Issues & Responses

- **Overlapping geometry on export:** N-gons and overlapping faces look fine in the viewport but cause problems in render. Teach Merge by Distance and check for duplicated vertices.
- **Render has artifacts:** Check for inverted normals (blue in Overlay > Face Orientation mode). Flip normals before rendering.
- **Materials applied in wrong mode:** You must be in Object Mode to apply materials, not Edit Mode. Walk through this explicitly.

### Differentiation Notes

- **Students who need more support:** Provide a 10-step modeling reference card for the most common tool sequence.
- **Students who finish early:** Extension in project.md — add a second object to the scene and model it at a matching scale.

### Assessment Notes

- Project uses the 1–4 look-for rubric. Walk room during the modeling sessions. Verbal walkthrough during submission: students should identify 3 mesh tools they used and point to where each is visible in the model.
