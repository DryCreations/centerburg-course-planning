# Project: Blender First Model

**Course:** 3D Techniques (145120)
**Unit:** 1.3 — Blender Foundations
**Duration:** Weeks 5–7 (intentionally low-stakes familiarization project)

---

## Overview

Model a simple mechanical or everyday object entirely in Blender using polygon workflow. Apply two materials with distinct PBR values, set up 3-point lighting, and render a final hero image. This is a **confidence-building project** — the goal is workflow familiarity, not production-quality output. What you build here will directly inform how you approach Unit 2.1's Hard Surface Scene.

---

## Class Prompt: Blender First Model

### What You're Building

Choose **one** of the following object categories or propose your own (teacher approval needed for custom objects):

| Category | Examples |
|----------|---------|
| Everyday tool | Hammer, wrench, stapler, scissors (simplified) |
| Data storage / electronics | USB drive housing, game controller side panel, keyboard key |
| Simple furniture | Step stool, small table, chair leg assembly |
| Vehicle detail | Simplified wheel, exhaust pipe section, car door handle |
| Other hard surface | Door hinge, padlock, bottle cap |

> **Important:** Do not model an unmodified primitive. Your model MUST show at least: one loop cut, one extrude, and one bevel. The goal is to demonstrate that you can navigate Edit Mode.

### Minimum Requirements

| Requirement | Details |
|-------------|---------|
| Modeling | At least 3 distinct Edit Mode operations (Extrude, Loop Cut, Bevel minimum) |
| Materials | At least 2 materials with different PBR values (e.g., metal body + rubber grip) |
| Lighting | 3-point lighting setup (Key, Fill, Rim) |
| Render | 1 rendered hero image (PNG, minimum 1920×1080 px), Eevee acceptable |
| Files | `.blend` project file AND the render PNG both saved to portfolio folder |

### Milestones

| Milestone | Due | What to Show |
|-----------|-----|-------------|
| Object chosen + rough blocked in | End of Week 5 | Basic shape visible in Blender — at least primitive forms in place |
| Edit Mode work in progress | Week 6, Day 2–3 | Loop cuts, extrudes, bevel visible; shape recognizable as the target object |
| Materials and lighting applied | Week 7, Day 1–2 | At least 2 materials assigned; 3 lights visible in Outliner |
| Final render saved to portfolio | Week 7, Day 4–5 (before quiz) | PNG render file saved; `.blend` file saved |
