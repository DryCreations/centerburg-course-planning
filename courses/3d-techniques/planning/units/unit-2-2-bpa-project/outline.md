## Student Overview

### What Is This Unit About?

BPA submissions aren't just finished work — they require documented process. This unit is dedicated to advancing your BPA entry, creating the process documentation that judges score, and developing a printable 3D file that moves from Blender to the printer. You'll connect creative work to competition requirements explicitly.

### What You'll Be Able to Do

By the end of this unit you will be able to:

- Advance your BPA project to an intermediate draft state with documented iterations
- Create a process documentation set (concept sketches, iterations, render progression)
- Prepare a model for 3D printing: check wall thickness, generate supports, slice, and preview
- Compile a development portfolio documenting the journey from concept to current state

### Common Issues & Responses

- **Change log is vague ("I changed stuff"):** Require before/after screenshots for each change; change log entry must name what changed AND why.
- **Model fails slicer check:** Don't allow submission without a clean slicer preview. Most failures are non-manifold geometry from boolean operations.

### Differentiation Notes

- **Students who need more support:** Provide a change log table template with columns: Screenshot Before, Screenshot After, Change Made, Reason.
- **Students who finish early:** Extension in lab-2.md — research a real product development case study and identify parallels to their own iteration process.
