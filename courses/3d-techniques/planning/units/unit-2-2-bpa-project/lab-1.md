# Lab: BPA Entry — Rendering & Documentation Sprint

**Course:** 3D Techniques (145120)
**Unit:** 2.2 — BPA Project Production
**Duration:** Weeks 16–17 (render/documentation phase)

---

## Objective

Produce a publication-quality render package for your BPA entry (#425 modeling or #440/#V11 animation) and assemble the accompanying documentation — the materials that judges evaluate alongside the visual work.

---

## Background

Judges score BPA entries from the documentation package as well as the performance or submission. A strong model with weak documentation loses to a slightly lesser model with thorough, professional documentation. This lab closes that gap.

---

## Part A — Final Render Package (#425 Computer Modeling)

*Skip to Part B if you are on an animation track.*

### Step 1: Render Hero Image
1. Confirm scene is complete: lighting, materials, camera angle.
2. Switch to **Cycles** render engine. Set samples to minimum 128 (higher if time allows).
3. Set output resolution: 1920×1080 px minimum. Render.
4. Save as: `[YourName]_BPA425_HeroRender.png`

### Step 2: Wireframe Render
5. In the Material Properties, enable **Wireframe Overlay** (or use a Freestyle line render).
6. Render the same camera angle showing the edge structure clearly.
7. Save as: `[YourName]_BPA425_Wireframe.png`

### Step 3: Multi-Angle Renders (Minimum 3 Views)
8. Render: front, 3/4 view, and one detail close-up. Name sequentially: `_Front.png`, `_ThreeQuarter.png`, `_Detail.png`.

### Step 4: Research Profile
9. Complete or finalize the Research Profile document. Required sections:
   - Industry background (what industry uses this type of object and why)
   - Design purpose and requirements
   - Production process summary (4–6 steps with screenshots)
   - Dimensional/specification notes (materials modeled, polygon count, file size)
   - Reflection: what would improve the design in a real-world application

---

## Part B — Final Render Package (#440 Computer Animation Team)

*Skip to Part C if #425.*

### Step 1: Complete Animation
1. Confirm all scenes are complete: animation keys set, sound imported, titles/credits added.
2. Render full animation as image sequence (PNG). Submit each member's section if split by scene.

### Step 2: Compile to Video
3. In Blender's **Video Sequencer**, assemble the image sequences.
4. Add your audio track.
5. Export as MP4: H.264, 1920×1080, 24 fps.
6. Save as: `[TeamName]_BPA440_Final.mp4`

### Step 3: Team Documentation Package
7. Compile: design brief, storyboard, role assignment sheet, production log (weekly progress notes), and a one-page reflection.
