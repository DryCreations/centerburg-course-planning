## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | CAD = Computer-Aided Design — standard industry terminology |
| 2 | C | OnShape is the Q1 CAD tool; Blender starts Q2 |
| 3 | B | Blender is the primary tool from Q2 onward |
| 4 | C | STL (Standard Tessellation Language) is the universal 3D printing format |
| 5 | B | Additive manufacturing builds up material, vs. subtractive machining which removes material |
| 6 | B | WebXam = Ohio CTE's standardized End-of-Course assessment |
| 7 | C | Strand 7 is the largest EOC area (~51%); low score there requires building 3D/animation skills |
| 8 | A | Design → Export STL → Import into slicer (Cura/PrusaSlicer) → Print is the correct sequence |
| 9 | C | Hard surface modeling = mechanical/man-made rigid objects. Car door is the correct match |
| 10 | C | BPA project planning starts at the Unit 1.4 showcase (Q1 Weeks 8–9); early concept formation is key |
