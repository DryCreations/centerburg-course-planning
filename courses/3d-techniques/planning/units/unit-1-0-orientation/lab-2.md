**Course:** 3D Techniques (145120)

**Duration:** Week 1–2 | **Tools Needed:** OnShape, Blender, Google Sites (or approved platform)

## Objective

By the end of this lab, students will be able to:

- Create a live portfolio site with navigation pages for all course units
- Write 3 SMART learning goals connected to pretest strand gaps
- Complete the software scavenger hunt documenting key tools

## Background

This portfolio is the container for every render, model file, and deliverable this year. Organize it correctly now — disorganized files in Q4 will cost you significant time.

## Instructions

### Step 1 — Create Your Portfolio Site

Create a Google Site (or teacher-approved platform). Title: `[Your Name] — 3D Techniques Portfolio`. Add navigation pages for: Home / About, Units 1.0 through 4.2, and Credentials. Make it publicly viewable.

Complete the signed equipment safety form. Note the date on your portfolio Home page.

### Step 3 — Pretest Strand Table + SMART Goals

Using your pretest scores from the lab, build a table: Strand, score %, WebXam weight %, gap. Circle the 2 lowest strands. Write 3 SMART goals — one per lowest-priority strand plus one for your production goal.

### Step 4 — Software Scavenger Hunt Answers

Add your software scavenger hunt answers to the portfolio Home page. Include: OnShape answers (3 questions) and Blender answers (3 questions). All 6 answers must be present before submitting.

### Step 5 — Submit

Share your portfolio URL with the teacher. Ensure all navigation pages exist (even if empty — you'll fill them in over the course).

## Class Prompt: Setup & Learning Goals

### Deliverable 1 — Toolchain Setup Checklist

Complete each item and mark it ✓ when done. Show your teacher each completed setup.

| Item | Steps | ✓ |
|------|-------|---|
| **OnShape account** | Go to onshape.com → Create a free EDU account using your school email → Confirm via email → Log in | ☐ |
| **OnShape desktop access** | Test that you can open OnShape in Chrome or Edge in the classroom and create a new document | ☐ |
| **Blender installed** | Teacher will direct you: either lab workstations have Blender 4.x, or download from blender.org to a personal drive | ☐ |
| **Blender launches** | Open Blender and confirm you see the default startup file (cube, camera, light in viewport) | ☐ |
| **Slicer software** | Open Cura or PrusaSlicer on the lab workstation; confirm the school printers appear in the printer list | ☐ |
| **Class portfolio folder** | Create a folder system per teacher instructions (cloud or local) for storing render outputs and project files | ☐ |
| **BPA account** | If not already registered: teacher will provide the chapter registration link (optional at this stage) | ☐ |

### Deliverable 2 — Software Scavenger Hunt

Complete the following tasks in OnShape and Blender. Write your answers on paper or in a shared document:

**OnShape:**
- What is the keyboard shortcut to sketch a circle?
- Where in the interface is the "Feature Tree" (the list of operations applied to your part)?
- What does the "Constrain fully" indicator mean?

**Blender:**
- What key opens the Add menu (to add new objects)?
- What key toggles between Object Mode and Edit Mode?
- What is shown in the Outliner panel (top right)?
