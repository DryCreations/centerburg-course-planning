# Template Needs — Design Techniques

This document catalogs every template that needs to be built for student use. The teacher exemplar uses the **same template** as students — your Ridgeline Supply Co. exemplar is your model filled-in version of each template.

Templates fall into three categories:
- **Adobe Express templates** — shared via Express link; students make a copy and build in the tool
- **Document templates** — Google Docs/Slides shared via Classroom; students make a copy and fill in
- **Google Sites template** — a published teacher-built example site; students create their own site using it as a structural reference

> **Philosophy:** Labs that are exploratory or open-ended use lightweight scaffold templates (tables and prompts). Labs that produce a specific document or design artifact use a more structured template with preset layout. Projects lean toward from-scratch creation with a content checklist — not a pre-built layout.

## Notes on Exemplar Use

Your teacher exemplar for every template is a filled-in version of the student template using **Ridgeline Supply Co.** content. This means:

- Build the template first (blank structure)
- Then fill it in with Ridgeline content to create the exemplar
- Share only the blank template with students
- Show the Ridgeline exemplar during instruction, then put it away while students work

For Adobe Express templates: duplicate the blank template into your own teacher workspace and fill in Ridgeline content. Keep the blank template in a shared student library and the filled-in version in a teacher-only folder.

For Google Doc templates: the blank version goes in Google Classroom (make-a-copy link). Your filled-in Ridgeline version stays in your teacher Drive — you project it during the intro, then close it.
