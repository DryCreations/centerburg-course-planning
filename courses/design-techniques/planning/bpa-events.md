# Design Techniques — BPA Competition Reference

**Course:** 145095 Design Techniques
**See also:** [Master BPA Events Reference](../../../program/bpa/bpa-events-master.md)

> **Cross-course note:** Students may compete in any BPA event. Events below are the strongest natural fits for Design Techniques content. Students from other courses are equally welcome to pursue these events.

---

## Competition Pathway

```
School Competition (January)  →  Ohio State Conference (Feb/Mar)  →  NLC Nashville (May 6–10)
Virtual Events: skip qualifying entirely — register Dec 1, submit Jan 15
```

Advancing at each stage is the student's choice. See the [master document](../../../program/bpa/bpa-events-master.md) for full dates and details.

---

## Primary Events for Design Techniques Students

### #410 Graphic Design Promotion *(Recommended primary event)*

| | |
|---|---|
| **Format** | Individual |
| **Deliverable** | Logo design + promotional flyer built around an assigned theme |
| **Division** | Secondary and Post-Secondary |
| **BPA Topic** | Assigned theme/prompt each year by WSAP |
| **Class Connection** | Unit 1.3 (Brand Style Guide — logo portion) and Unit 2.3 (BPA production phase) |
| **BPA vs. Class** | Class: fictional brand identity. BPA: same skills, official WSAP theme. Students who want to compete use the WSAP prompt; others use the class client. Work is graded on the same class rubric either way. |
| **Why it fits** | This is the most direct BPA event for graphic design. Logo + promotional flyer is exactly what the course builds toward. Strong alignment with 7.4 (Graphics), 7.5 (Typography), and 7.3 (Production) CTE standards. |

---

### #405 Advanced Desktop Publishing *(Strong solo option)*

| | |
|---|---|
| **Format** | Individual |
| **Deliverable** | Multi-page interactive document created in Illustrator® or InDesign® |
| **Class Connection** | Brand style guide (Unit 1.3) or marketing materials from the capstone (Unit 4.3) |
| **Notes** | Good for students who prefer an extended document-design challenge over a single promotional piece. |

---

### #455 User Experience Design Team *(Team option — design + strategy)*

| | |
|---|---|
| **Format** | Team (2–3) |
| **Deliverable** | Prototype digital experiences for a brand: web presence, mobile, social media — with UX rationale |
| **Class Connection** | Unit 1.4 (UX/UI + website project) and Unit 4.3 (capstone brand identity) |
| **BPA vs. Class** | Class website + capstone are the foundation. BPA version adds more rigorous UX documentation and mobile prototyping. Requires outside-class work to complete. |
| **Why it fits** | The course's website in Unit 1.4 and brand identity capstone are built around UX thinking. 455 rewards the full design thinking process documented throughout the course. |

---

### #460 Visual Design Team – Pilot *(Team brand identity option)*

| | |
|---|---|
| **Format** | Team (2–3) |
| **Deliverable** | Create a new brand image for a company using team-based visual design strategies |
| **Class Connection** | Unit 4.3 (Brand Identity Capstone) |
| **Notes** | Capstone project closely mirrors this event's deliverable. Team must present rationale for design decisions. Good option for strong design students who want collaborative work. |

---

### #420 Digital Media Production *(Video/animation option)*

| | |
|---|---|
| **Format** | Individual or Team (up to 3) |
| **Deliverable** | 1–2 min digital media production on assigned topic |
| **Class Connection** | Unit 2.3 (social media campaign video / animated content) |
| **Notes** | Accessible scope. Good alternative for students who lean toward animation and video over pure graphic design. |

Studying for the BPA event and the AC PRO exam reinforces the same skills.
