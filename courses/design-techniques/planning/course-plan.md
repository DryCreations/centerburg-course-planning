# Design Techniques — Course Planning

**Subject Code:** 145095
**School Course Name:** Engineering Design
**Career Field:** Information Technology
**Pathway:** Interactive Media (N1)
**CTAG Eligible:** Yes — CTIM008 Digital Page Layout and Design (3 SH)
**CTAG Reference:** See [ctag-alignment.md](ctag-alignment.md) for full standards mapping and eligibility requirements
**Industry Credential:** Adobe Certified Professional — Content Creation and Marketing Using Adobe Express

## Course Overview

Students learn techniques for transforming photographic images through use of digital cameras, computers, and mobile devices, while building fluency in Adobe Express as a content creation and digital marketing platform. Students develop a professional portfolio throughout the course, adding polished pieces each quarter. The course prepares students for the Ohio CTE WebXam and the Adobe Certified Professional credential exam.

## Portfolio Thread

Students create a **professional portfolio** in Google Sites starting Week 1. Each major project is refined and added as a portfolio piece. The portfolio serves as:
- A running showcase of skill development across all units
- The primary artifact for the BPA competition season
- Evidence of credential-ready skills for the AC PRO exam
- A capstone deliverable presented at end of year

| Quarter | Portfolio Additions |
|---------|--------------------|
| Q1 | Brand identity sampler, type style guide, wireframe/layout, marketing plan |
| Q2 | Photo essay, BPA project proposal, BPA project draft, social media campaign |
| Q3 | Polished BPA entry, AI design exploration, freelance business plan |
| Q4 | Client delivery package, brand identity capstone, career reflection |

## BPA Competition Integration

See the [BPA competition planning document](../../../program/bpa/competition-planning.md) for the full season calendar, national deadlines, and how to run a local competition.

### Course Alignment

Design Techniques' Strand 7 content — graphics, typography, photography, and multimedia production — maps directly to BPA's **Digital Communication & Design** assessment area (400s events). The Adobe Express credential adds a digital marketing and content strategy dimension that strengthens BPA project rationale and presentation. Competition projects double as course assignments and portfolio pieces.

### Recommended Events

Students select **one primary event** and one backup. Events below are ordered from strongest to most accessible first-year option.

| Event # | Event Name | Format | Standards Aligned | Notes |
|---|---|---|---|---|
| **410** | Graphic Design Promotion | Individual | Strand 7.3 (Graphics), 7.4 (Typography) | Logo design + promotional flyer. Strong default choice; clear rubric; good first-year event. |
| **405** | Advanced Desktop Publishing | Individual | Strand 7.3 (Graphics & Design) | Create interactive documents using design software. |
| **420** | Digital Media Production | Ind. or Team | Strand 7.1 (Interactive Media), 7.3 | 1–2 min digital media production. Accessible scope. |
| **V06** | Promotional Photography | Individual (Virtual) | Strand 7.5 (Photography) | DSLR + image editing. **National-only virtual event** — no state qualification needed. Submit online by Jan 15. |
| **V01** | Virtual Multimedia & Promotion (Ind.) | Individual (Virtual) | Strand 7.1 (Interactive Media) | **National-only virtual event** — no state qualification needed. Submit online by Jan 15. |
| **490** | DC&D Concepts — Open | Objective Test | Strand 2, 7 (general IT/media) | Knowledge test taken at competition. Lowest barrier — no project required. Good backup option. |

### School Year Integration Timeline

| Quarter | BPA Activity | Connection to Course Work |
|---|---|---|
| **Q1** (Aug–Oct) | Introduce BPA; students review WSAP guidelines; select event | Foundation skills (image editing, color theory, tools) — students identify which skills map to their chosen event |
| **Q2** (Oct–Jan) | Project work begins; topic/prompt received from WSAP guidelines; first drafts complete | Applied skills (layering, masking, special effects, typography) — BPA project is a course assignment |
| **Q3** (Jan–Feb) | Finalize project; hold **local school competition** (January) | Peer critique and revision using WSAP rubric; presentation skills |
| **Q3** (Feb–Mar) | **Ohio State Leadership Conference** *(confirm exact date with Ohio State Advisor)* | State competitors represent the chapter; remaining students finalize portfolios |
| **Q4** (Apr–May) | **NLC May 6–10** (Nashville) for state qualifiers; debrief and reflection for all | Portfolio finalization; career connections |

> **Virtual event students:** Register by **December 1** and submit work by **January 15** via upload.bpa.org — these events skip state qualification entirely.

### Local Competition (January)

Run a school-level competition before the state conference:
- Students present Graphic Design Promotion, Desktop Publishing portfolio, or Digital Media Production to a panel
- Invite BAC members and/or staff as judges; use the official WSAP scoring rubric
- All students compete; top performers advance to state
- Can be completed in 1–2 class periods

## Credential Exam Preparation

- Adobe Express is used as the primary tool from Day 1, building familiarity organically
- Digital marketing concepts (AC PRO Domain 1) are taught as the "why" behind every design project
- Express-specific features (templates, libraries, brands, PDF tools, scheduling) are embedded as mini-lessons during project work
- Dedicated AC PRO review sessions run alongside WebXam review in Q4
- Students take the AC PRO exam after the WebXam initial test, during weeks 32–35
