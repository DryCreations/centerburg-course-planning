## Part B — Color Interaction & Composition Experiment

Your teacher will share an Adobe Express template. It has several pages set up for you to experiment with — you are modifying it, not building from scratch.

### Step 3: Work Through the Template Pages

The template includes:

- **Page 1 — Foreground/Background:** A background color and a shape in the foreground. Change the colors. Try different combinations. Note which ones look good, which look bad, which look ugly, and which look weird. Write a word or two next to each attempt.

- **Page 2 — Opacity & Blending:** Two overlapping shapes with different colors. Adjust the opacity of one (try 30%, 60%, 90%). Then try different blend modes (Multiply, Overlay, Screen). Describe what each blend mode does to the colors where they overlap.

- **Page 3 — Text on Backgrounds:** Text placed over a colored background. Try 3 different color combinations (dark text/light bg, light text/dark bg, similar hues). Assess legibility: which is easiest to read? Which is hardest?

- **Page 4 — More text legibility:** Repeat with different colors. Try a patterned or image background with text over it. What makes text hard to read on images?

For each page, write a short observation (1–2 sentences is fine).
