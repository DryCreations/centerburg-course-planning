# Lab 2: Brand Color & Graphics Sampler

**Course:** Design Techniques (145095)
**Unit:** 1.2 — Graphics Fundamentals: Color, Shape & Image Editing in Express
**Duration:** 3 days | **Weeks:** 4–5
**Tools Needed:** Adobe Express, color theory reference, WebAIM Contrast Checker

---

## Objective

By the end of this lab, students will be able to:

- Create a 4-page Adobe Express brand document demonstrating color theory, harmony, composition, and export format knowledge
- Annotate every design decision with a brief written rationale ("why" not just "what")
- Export files in appropriate formats with correct settings

---

## Background

This sampler becomes the visual vocabulary for your entire brand this year. The color and composition decisions you make here carry forward into Unit 1.3's Brand Style Guide.

---

## Instructions

### Step 1 — Page 1: Color Palette

Create 5 color swatches for your personal brand. For each, include: hex code, RGB values, and 1 sentence explaining the color choice (color psychology + brand rationale). Use the color picker in Express to apply them from your brand kit.

### Step 2 — Page 2: Color Harmony + Contrast

Show 2 color harmony examples side-by-side (complementary + analogous). Then show a high-contrast and a low-contrast text example and label which passes accessibility requirements. Run a contrast check at WebAIM and note the ratio.

### Step 3 — Page 3: Composition Samples

Create 2 mini-compositions (1080×1080): one using rule-of-thirds, one using centered/symmetric balance. Label the composition principle on each one.

### Step 4 — Page 4: Export Format Guide

Create a table or visual comparison: PNG vs. JPEG vs. PDF. For each format, note: use case, file size tradeoff, and one Express export step. Include a screenshot from the Express export settings panel.

> **Checkpoint:** Before finishing, show your teacher Page 2 — the contrast ratio must be documented before you can submit.

## Class Prompt

### What You're Producing

A multi-section Adobe Express document (3–4 pages) that functions as a color theory and graphics showcase for your personal brand. Professional designers create similar documents as "brand sheets" to prove their understanding of the brand's visual vocabulary.

### Pages Required

| Page | Content | Standards |
|------|---------|-----------|
| **Page 1 — Color Palette** | Primary palette (3–5 colors) with hex codes, RGB values, and 1-sentence rationale for each color (color theory + psychology) | 7.4.1, AC PRO 2.1.b |
| **Page 2 — Color Harmony + Contrast** | Show 2 harmony types (complementary + analogous); demonstrate high-contrast and low-contrast text examples; note accessibility status | AC PRO 2.1.b, 2.1.c |
| **Page 3 — Composition Samples** | 2 mini-compositions (1080×1080) using the brand palette: one with rule-of-thirds applied, one with centered/symmetric balance | AC PRO 2.1.c |
| **Page 4 — Export Guide** | Screenshot or table comparing PNG vs. JPEG vs. PDF for the compositions; note when each is appropriate | 7.4.7, AC PRO 5.3.a |

### Written Rationale

Each page must include brief annotations (callouts or text boxes) explaining WHY design choices were made:
- "I chose this red (#CC2200) because red communicates urgency and energy — appropriate for my brand in the [industry] space."
- "Complementary colors create the strongest visual contrast — ideal for CTA buttons and headlines."
