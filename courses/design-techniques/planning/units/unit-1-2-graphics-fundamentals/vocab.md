# Vocabulary: Graphics Fundamentals — Color, Shape & Image Editing

---

## Terms

| Term | Definition |
|------|------------|
| **RGB** | Red, Green, Blue — the additive color model used for screens and digital displays; values 0–255 for each channel |
| **CMYK** | Cyan, Magenta, Yellow, Key (Black) — the subtractive color model used for print; values as percentages |
| **Pantone (PMS)** | Pantone Matching System — a standardized spot color system used for precise, consistent ink colors in professional print |
| **Hex code** | Six-character alphanumeric code (e.g., #FF4400) representing an RGB color for web and digital use |
| **Color theory** | The study of how colors combine, contrast, and communicate — includes hue, saturation, value, and color harmony rules |
| **Color harmony** | Pleasing color combinations based on relationships on the color wheel: complementary, analogous, triadic, split-complementary |
| **Color psychology** | The study of how colors influence emotions, perceptions, and behavior in audiences |
| **Contrast** | The degree of difference between elements — especially important for text legibility (WCAG accessibility guidelines require sufficient contrast) |
| **Vector image** | Image defined by mathematical paths (points, curves, shapes) — infinitely scalable without quality loss; formats: AI, SVG, EPS |
| **Raster image** | Image made of a fixed grid of pixels — quality degrades when scaled up; formats: PNG, JPEG, GIF, TIFF |
| **Resolution** | Number of pixels per inch (PPI for screen) or dots per inch (DPI for print) — higher = more detail, larger file size |
| **Layer** | An independent, stackable level in a design file — allows non-destructive editing and complex compositions |
| **Blending mode** | A setting that determines how a layer interacts visually with layers beneath it (Multiply, Screen, Overlay, etc.) |
| **Opacity** | Transparency level of a layer or object — 100% = fully opaque; 0% = completely transparent |
| **Export format** | The file format a design is saved in for final delivery: PNG (transparent, lossless), JPEG (compressed), PDF (print-ready), SVG (scalable web) |
| **File compression** | Reducing file size — lossy (JPEG: removes data) vs. lossless (PNG, ZIP: retains all data) |
| **Composition** | The arrangement of visual elements in a design — rule of thirds, balance, emphasis, white space |
| **White space (negative space)** | Empty space in a design that gives the eye room to rest and elements room to breathe; improves readability and sophistication |
| **Rule of thirds** | A composition guideline: divide the image into a 3×3 grid; place important elements along the lines or intersections |
| **Duotone** | A two-color image effect: a grayscale photo with two color channels applied — creates a bold, stylized look |

---

## Key Distinctions

| Term 1 | Term 2 | Key Difference |
|--------|--------|---------------|
| RGB | CMYK | RGB = screen (additive color); CMYK = print (subtractive color) — never mix them without converting |
| Vector | Raster | Vector = mathematical paths → scales perfectly; Raster = pixels → degrades when enlarged |
| Lossy | Lossless | Lossy compression (JPEG) = smaller file but discards data; Lossless (PNG) = no data loss but larger |
| Opacity | Blending mode | Opacity = how transparent a layer is; Blending mode = how a layer's color interacts with what's underneath |

## Review Questions

1. A designer uses a CMYK logo file in a web project — the colors look washed out on screen. Why, and what should they have used instead?
2. What is the difference between a vector and a raster image? Give one example of each.
3. Explain the rule of thirds without mentioning any design software. How would you explain it to someone who has never heard of it?
4. A logo needs to print on a neon orange hat. Should the designer use an RGB hex code or a Pantone color? Why?
5. What is color psychology, and give one example of a color used purposefully to influence a specific emotion.
