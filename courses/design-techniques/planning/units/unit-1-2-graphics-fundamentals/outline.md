## Student Overview

### What Is This Unit About?

Color theory, vector vs. raster graphics, layer composition, and file export — these are the technical foundations every designer must know. This unit gives you the vocabulary and hands-on practice to make deliberate, explainable design decisions (not just "it looks good").

### What You'll Be Able to Do

By the end of this unit you will be able to:

- Apply color theory principles (harmony, psychology, contrast) to design decisions
- Distinguish vector from raster graphics and choose appropriate formats
- Build a multi-layer composition with blending modes in Adobe Express
- Export files in correct formats for print and web, and explain the difference

### Common Issues & Responses

- **Students confuse RGB and CMYK use cases:** Print the mnemonic: "RGB = Screens (Red/Green/Blue light), CMYK = Print (ink on paper)."
- **Annotations are vague:** Require students to write WHY, not just WHAT. "Blue was chosen for trust" is acceptable; "Blue is my favorite color" is not.

### Differentiation Notes

- **Students who need more support:** Provide a color wheel reference card and a completed Page 1 example to compare against.
- **Students who finish early:** Extension in lab-2.md — create a "dark mode" alternate version of the palette and explain the contrast considerations.

### Assessment Notes

- Lab: binary checklist — color harmony samples (2 types) and export format comparison table required.
- Lab-2: binary checklist — all 4 pages present with annotations; hex + RGB on all palette colors; composition principle labeled on Page 3.
