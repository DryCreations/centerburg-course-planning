# Vocabulary: Portfolio Setup & Professional Organization

---

## Terms

| Term | Definition |
|------|------------|
| **WebXam** | The Ohio ITA end-of-course online credential assessment; tests knowledge across all course strands |
| **Adobe Certified Professional (AC PRO)** | An industry-recognized credential earned by passing a design industry certification exam |
| **Adobe Express** | Adobe's web and mobile design tool used for graphics, publications, video, and web content |
| **Brand kit** | A predefined, reusable set of brand assets — approved colors, fonts, and logo files — organized for consistent application across all projects |
| **Portfolio** | A curated collection of your best work demonstrating skills, growth, and professional readiness |
| **Naming convention** | A systematic, consistent system for naming files and folders (e.g., `YYYYMMDD_ProjectName_Version`) to ensure organization and retrievability |
| **Asset library** | A centralized collection of approved brand graphics, photos, icons, and colors organized for reuse across projects |
| **Credential** | A recognized proof of skills competency earned by passing an industry or program-aligned assessment |
| **Digital portfolio** | A portfolio hosted online or in a web tool — reviewable by colleges, employers, and competition judges |

---

## Key Distinctions

| Term 1 | Term 2 | Key Difference |
|--------|--------|---------------|
| WebXam | AC PRO | WebXam = CTE course assessment (ITA credential); AC PRO = Adobe-specific industry credential |
| Brand kit | Asset library | Brand kit = pre-set of approved brand assets (colors/fonts/logos) saved digitally for reuse; asset library = broader collection of any reusable media file |
| Portfolio | Resume | Portfolio shows *evidence* of what you can do; resume lists accomplishments without showing them |
