## Questions

| # | Question | A | B | C | D | Answer |
|---|----------|---|---|---|---|--------|
| 1 | "Refinement" in the design process refers to: | Starting a project over from scratch | Making iterative improvements to a design based on testing, feedback, and evaluation | Finalizing a project with no further changes | Changing the entire concept | B |
| 2 | Usability testing involves: | A teacher scoring a rubric | Testing a design with real or representative users, observing how they complete tasks, and identifying points of confusion | Checking spell check in the software | Exporting the final file | B |
| 3 | A/B testing in design means: | Comparing version A (the rough draft) to version B (the final) | Testing two versions of a design with different audience groups to see which performs better based on measurable results | Testing on two different devices | Running the design through two proofreading rounds | B |
| 4 | A design audit reviews work for: | Client payment history | Quality, consistency, accessibility, and alignment with the original project brief | File size only | The number of fonts used | B |
| 5 | "Feedback documentation" in a professional context means: | Filing away all comments without acting on them | Recording which critique comments were received and what specific changes were made in response | Only saving email threads | Ignoring most feedback | B |
| 6 | The WCAG standard most commonly referenced for text accessibility is: | 2:1 contrast for all elements | 4.5:1 contrast ratio minimum for normal text, plus font size and keyboard navigability guidelines | 8:1 contrast for all text | Color-based measurement only | B |
| 7 | "Scanability" of a layout refers to: | How many images the page contains | How quickly a viewer's eye can move through the layout and absorb key information — aided by headings, white space, and visual hierarchy | How long it takes to print | How small the file is | B |
| 8 | **[HOT]** A poster scores well on aesthetic criteria but gets low scores on readability. Feedback says "body text is 8pt gray on white with 1.2 line spacing." | 9 | A "pre-submission review" before delivering a design means: | Printing a rough copy on regular paper | Checking every deliverable against the project brief and evaluation criteria — verifying required formats, content accuracy, and technical specifications are correct before delivery | Submitting a rough draft first to test the upload system | Having a teammate submit the entry on your behalf | B |
| 10 | A "revision history" log in a design project: | Lists all fonts used | Documents changes made at each iteration — what changed, why, and when | Records the clients' personal preferences | Is only useful for print projects | B |
| 11 | **[HOT]** A designer receives this critique note: "The hierarchy is unclear — I read the tagline before the headline." What does this mean and what would you do to fix it? | The tagline is in the wrong language | Visual hierarchy is not guiding the viewer's eye in the intended order — fix: make the headline significantly larger and/or higher contrast than the tagline, and reduce the tagline's visual weight | The font used is incorrect | The layout has too many columns | B |
