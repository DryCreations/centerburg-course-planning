## Standards & Rubric

Walk the room as students work. Ask students to point to evidence for each standard before scoring.

| Standard | Description | Look-For (Proficient = 3) | Beginning (1) | Developing (2) | Proficient (3) | Advanced (4) |
|----------|-------------|--------------------------|---------------|----------------|----------------|--------------|
| **2.11.3** | Usability testing | Peer test conducted; results documented | No test | Test done; no notes | Test + written results | Test + results + at least 1 design change that responded to the test |
| **2.11.7** | Portfolio curation | 1 annotation per piece in the portfolio | No annotations | 1 annotation total | 1 annotation per piece | Annotation + specific design decision explained per piece |
| **2.12.1** | Refinement | Revision history shows 3+ tracked changes | No history | 1–2 changes noted | 3+ changes with "before" description | 3+ changes with before/after + rationale per change |
| **2.12.2** | Accessible design | WCAG audit table shows passing contrast and alt text | No audit | Audit done; fails | Audit passing: contrast + alt text | Audit + font size + readability + one remediation note |
| **2.12.3** | Design audit | Self-audit table completed for all deliverables | No audit | Partial audit (1–2 pieces) | Full audit: all pieces reviewed | Full audit + prioritized action list from audit results |
| **2.12.5** | Feedback | Changes traced to specific feedback source | No feedback loop | Changes made; sources not noted | Changes traced to source (critique or teacher) | Changes + written explanation of why each change improved the piece |
| **2.12.6** | BPA submission | WSAP rubric reviewed; submission package complete | Not reviewed | Rubric reviewed; package incomplete | WSAP reviewed + complete package | Package + self-score on WSAP + plan for state submission |
| **AC PRO 2.3.a** | Accessibility verification | Alt text, contrast, and readability verified for all pieces | None verified | 1 element verified | All three verified | All three + screen reader walkthrough note |
| **AC PRO 4.3** | Presentation / annotation | Annotation document submitted | Not submitted | Partial annotations | Full annotation doc submitted | Annotation + verbal walkthrough delivered to teacher |
| **AC PRO 5.1** | Export final files | Final files in correct format and size per WSAP | Wrong format | Correct format; wrong size | Correct format + size | All exports + a delivery checklist matching WSAP specs |
