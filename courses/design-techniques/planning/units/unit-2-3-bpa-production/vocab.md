# Vocabulary: Design Production & Social Media Campaigns

---

## Terms

| Term | Definition |
|------|------------|
| **Graphic design promotion** | A design project created to promote a product, event, organization, or cause — combining brand identity, typography, imagery, and layout to persuade a target audience |
| **Print layout** | The arrangement of visual and text elements on a physical page — considers trim, bleed, margins, and safe zones |
| **Bleed** | The area of a print design that extends past the trim line — ensures color/images reach the edge when the paper is cut |
| **Mockup** | A realistic preview of a design placed in a real-world context (e.g., logo on a T-shirt, poster on a wall) — used for presentation and client approval |
| **Social media post** | A formatted piece of digital content — image, video, carousel, or text — published to a social network for a defined audience |
| **Platform specifications** | Required dimensions, aspect ratios, and file formats for each social media platform — differ between platforms and content types |
| **Template** | A pre-designed layout that can be customized — professional design tools include templates for common formats (posts, stories, posters, flyers) |
| **Thumbnail** | A small, low-resolution preview of an image or video used for navigating or selecting content |
| **Grid system** | A structural framework of horizontal and vertical lines that organizes elements into a consistent layout — helps create unity across multi-piece campaigns |
| **Campaign consistency** | Maintaining visual unity (same colors, fonts, imagery style, logo placement) across all pieces in a multi-platform marketing campaign |
| **Accessible design** | Design that can be understood and used by people with disabilities — includes sufficient color contrast, readable font sizes, and descriptive alt text |
| **Color contrast ratio** | A numeric measure of the difference in brightness between text and background — WCAG standards require 4.5:1 minimum for normal text |
| **PDF export** | Exporting a design as a Portable Document Format file — preserves layout and fonts across devices; used for print-ready files and professional sharing |
| **Social media strategy** | A plan documenting which platforms to use, what content to post, at what frequency, to achieve a specific marketing goal |
| **Proofreading** | The final review of a design to catch spelling, grammar, alignment, and consistency errors before production |
| **Design critique** | A structured peer or professional feedback process based on pre-established design criteria — identifies strengths and specific areas for improvement |

## Review Questions

1. You're designing a poster that will be commercially printed. The background color doesn't reach the edge when printed. What did you forget to add?
2. A designer posts an Instagram ad graphic that was designed at 1920×1080 pixels. Why does it look awkward in the feed? What dimensions should she use?
3. What makes a multi-piece campaign look "consistent"? Name 3 visual elements that should be repeated across all pieces.
4. What is the minimum WCAG color contrast ratio for readable body text? Why does this matter in design?
5. What is the difference between a "mockup" and a "final file"? When do you use each?
