# Vocabulary: Production Workflow & Marketing Plans

---

## Terms

| Term | Definition |
|------|------------|
| **Production workflow** | A structured sequence of steps from project intake to final delivery — includes briefing, planning, design, review, revision, and delivery phases |
| **Project brief** | A written document that defines project scope, target audience, deliverables, timeline, budget, and success criteria before production begins |
| **Scope creep** | The gradual expansion of project deliverables beyond the original brief — usually unplanned and without adjusting budget or deadline |
| **Iteration** | One cycle of create → review → revise within a design production process; professional projects typically go through multiple iterations |
| **Version control** | A system for tracking, saving, and managing different versions of a file — prevents loss of work and allows rollback; file naming conventions are a basic form |
| **Marketing plan** | A strategic document that identifies a target market, marketing goals, chosen tactics, channels, budget, and a measurement/evaluation strategy |
| **Target market** | A specific, defined group of consumers most likely to buy a product or service — defined by demographics, psychographics, and behavior |
| **Buyer persona** | A semi-fictional, detailed character profile representing an ideal customer — includes name, age, goals, frustrations, media habits, and purchasing behavior |
| **Content marketing** | A strategy that creates and distributes valuable, non-promotional content to attract and retain a clearly defined audience |
| **Content calendar** | A scheduling tool (usually a spreadsheet or table) that maps out what content will be published, on what platform, on what date |
| **Marketing channel** | A platform or medium through which marketing messages reach a target audience — e.g., Instagram, email newsletter, YouTube, print flyer |
| **Distribution** | The process of delivering a product or marketing message to its intended audience through the right channels |
| **Call to action (CTA)** | A direct instruction in a marketing piece that prompts the audience to take a specific next step: "Buy Now," "Register Today," "Follow Us" |
| **Unique value proposition (UVP)** | A clear, concise statement of why a customer should choose this product/service over competitors — what unique benefit it offers |
| **Feedback loop** | A formal or informal process by which a designer receives responses to their work and uses that information to make improvements |
| **Client handoff** | The final phase of a production workflow — delivering all final files, usage guidelines, and supporting documentation to the client |
| **Asset inventory** | A comprehensive list of all design assets (logos, fonts, image files, color codes) that belong to a project — included in the project deliverables |

3. Explain how a content calendar helps a marketing team execute a strategy.
