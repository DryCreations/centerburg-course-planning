# Lab: Project Proposal + Marketing Brief

**Course:** Design Techniques (145095)
**Unit:** 2.2 — Production Workflow, Project Proposals & Marketing Plans
**Duration:** Weeks 14–15

---

## Objective

Write a professional project brief and marketing brief for your BPA promotion project (or a teacher-approved class project). Apply production workflow vocabulary by structuring the planning documents that will drive every design decision in Units 2.3–3.1.

---

## Background

Real designers don't start designing until they've written the brief. This lab produces the planning documents you'll use for the next three weeks of work. These are also the types of documents evaluated in BPA events #410 (Graphic Design Promotion) and #505 (Entrepreneurship).

---

## Part A — Project Brief

### Week 14

Write a one-page project brief for your design project. Use this structure:

| Section | What to Include | Min |
|---------|----------------|-----|
| Project name | Working title | 1 line |
| Client description | Who you're designing for (real or fictional) | 2–3 sentences |
| Problem statement | What communication problem does this project solve? | 1–2 sentences |
| Target audience | Who is the intended viewer/user? Include demographics and psychographics | 1 paragraph |
| Deliverables | List each item you will produce | Minimum 4 items |
| Timeline | Milestones and dates | Table with 4+ rows |
| Constraints | Budget, brand guidelines, format restrictions | 1 paragraph |
| Success criteria | How will you know this project succeeded? | 2–3 measurable criteria |

## Part C — Marketing Brief

### Week 15

Write a one-page marketing brief. Use this structure:

| Section | What to Include |
|---------|----------------|
| Campaign name | |
| Marketing goal | 1 specific, measurable goal (e.g., "Get 200 signups by March 1") |
| Target audience | Reference your buyer persona from Part B |
| Unique value proposition | 1–2 sentences: what makes this product/brand stand out? |
| Channels | 3 specific channels (e.g., Instagram, flyer, school announcement) |
| Key messages | 1 main message + 1 differentiator per channel (table) |
| CTA | What is the single action you want the audience to take? |
| Asset list | List the design assets needed (e.g., Instagram post, header image, poster) |
