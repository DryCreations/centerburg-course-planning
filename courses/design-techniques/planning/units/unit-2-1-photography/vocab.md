# Vocabulary: Photography — Capture & Editing

---

## Terms

| Term | Definition |
|------|------------|
| **Aperture** | The adjustable opening in a camera lens that controls how much light enters; measured in f-stops — smaller f-number = wider opening = more light + shallow depth of field |
| **Shutter speed** | The length of time the camera sensor is exposed to light — fast speeds freeze motion; slow speeds create motion blur |
| **ISO** | The camera sensor's sensitivity to light — low ISO (100) = clean image; high ISO (3200+) = brighter but grainier |
| **Exposure triangle** | The relationship between aperture, shutter speed, and ISO — all three must be balanced to achieve correct exposure |
| **Depth of field** | The range of distance in a photo that appears sharp — controlled primarily by aperture; wide aperture = shallow DoF (blurred background) |
| **White balance** | Camera setting that corrects for color temperature of the light source — ensures white objects look white under different light types (daylight, tungsten, fluorescent) |
| **Composition** | The deliberate arrangement of subjects within the frame; techniques include rule of thirds, leading lines, framing, and symmetry |
| **Rule of thirds (photo)** | Divide the frame into a 3×3 grid; place the main subject at one of the four intersections for more dynamic composition |
| **Leading lines** | Compositional technique where lines in the scene (roads, fences, hallways) guide the viewer's eye toward the subject |
| **Key light** | The primary, strongest light source in a photography or studio lighting setup |
| **Fill light** | A secondary light used to reduce shadows cast by the key light — less intense than key |
| **Rim / backlight** | A light behind and above the subject that creates a separation edge from the background — adds depth |
| **Bounce lighting** | Technique of reflecting light off a surface (card, wall, ceiling) to soften shadows and distribute light |
| **Color correction** | Adjusting exposure, white balance, highlights, shadows, and color balance in post-processing to achieve accurate representation |
| **Color grading** | Going beyond correction to apply a specific visual mood — warm/cool tone, cinematic look, brand-aligned aesthetic |
| **Cropping** | Removing portions of an image to improve composition, focus attention, or fit a target format |
| **Digital photography** | Photography using electronic sensors instead of film — image stored as a digital file |
| **RAW format** | Uncompressed camera file that retains all sensor data — allows maximum editing flexibility but is very large |

---

## Key Distinctions

| Term 1 | Term 2 | Key Difference |
|--------|--------|---------------|
| Aperture | Shutter speed | Aperture = controls light amount + depth of field; Shutter speed = controls light duration + motion |
| Color correction | Color grading | Correction = fixing errors to achieve accuracy; Grading = creative stylization for mood/brand |
| RAW | JPEG | RAW = maximum data, non-destructive editing; JPEG = compressed, some data lost at capture |
| Key light | Fill light | Key = primary, bright, directional; Fill = secondary, soft, reduces shadows |
