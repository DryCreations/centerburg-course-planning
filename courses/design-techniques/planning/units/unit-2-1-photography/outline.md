## Student Overview

### What Is This Unit About?

This is the only unit in the course where you pick up a physical camera. You will learn the exposure triangle (aperture, shutter speed, ISO), how to set up 3-point lighting, and how to edit photographs in Adobe Express. The edited images feed directly into the promotional campaign you build in Unit 2.3.

### What You'll Be Able to Do

By the end of this unit you will be able to:

- Use manual camera settings (aperture, shutter, ISO) to achieve intentional exposure
- Set up a 3-point lighting configuration and describe the role of each light
- Apply color correction, cropping, and effects to images in Adobe Express
- Document technical shooting decisions in a structured annotation table

### Common Issues & Responses

- **Students shoot everything in auto mode:** Lock manual exposure in the first lab session; auto mode is not accepted for the exposure experiment.
- **Annotations are missing:** Each image page in the essay document must have both a settings note AND an editing decision note before the checklist is complete.

### Differentiation Notes

- **Students who need more support:** Provide an exposure cheat sheet (ISO/aperture/shutter combinations for common lighting situations).
- **Students who finish early:** Extension in lab-2.md — produce a 30-second edited video from the same session.

### Assessment Notes

- Lab-2 uses a binary checklist. Key evidence: 6+ edited images, technical specs table with all 3 settings per image, before/after comparison for 2 images, reflection paragraph.
