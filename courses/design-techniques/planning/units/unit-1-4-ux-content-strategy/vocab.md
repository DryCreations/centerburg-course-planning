# Vocabulary: Multimedia Tools, UX/UI & Content Strategy

---

## Terms

| Term | Definition |
|------|------------|
| **UX (User Experience)** | The overall experience a person has when interacting with a product or system — how easy, efficient, and enjoyable it is to use |
| **UI (User Interface)** | The visual and interactive elements a user sees and interacts with — buttons, menus, layouts, icons, typography on screen |
| **Wireframe** | A low-fidelity visual layout showing placement of content and interface elements — no color or final design; maps structure only |
| **Prototype** | A simulated or interactive model of a product built for testing before final production |
| **Journey mapping** | Visualizing the steps a user takes to achieve a goal — identifies pain points and design opportunities |
| **UX design process** | A structured iterative workflow: Discover, Define, Ideate, Prototype, Test, Implement |
| **Navigation** | The system of menus, links, and buttons that allows users to move through a website or app |
| **Call to action (CTA)** | A design element that prompts the user to take a specific step — "Buy Now," "Learn More," "Sign Up" |
| **SEO (Search Engine Optimization)** | Techniques used to improve a website's visibility in search engine results — keywords, alt text, metadata, page structure |
| **Keyword** | A word or phrase that users type into a search engine; used in SEO to match content with user queries |
| **Alt text (alternative text)** | A written description of an image embedded in HTML — allows screen readers to describe the image to visually impaired users |
| **Responsive design** | A design approach that makes layouts automatically adapt to different screen sizes — desktop, tablet, mobile |
| **Template** | A pre-designed layout that can be modified with custom content — speeds production while maintaining structural consistency |
| **Client persona** | A detailed fictional profile of the ideal customer or user — used to guide design decisions; similar to a buyer persona, but applied specifically to UX and design contexts |
| **Stakeholder review** | Presenting a design to the client, team, or panel for feedback and approval before proceeding to final production |
| **Content strategy** | A plan for what content to create, for whom, through which channels, and on what schedule |

---

## Key Distinctions

| Term 1 | Term 2 | Key Difference |
|--------|--------|---------------|
| UX | UI | UX = the experience (how it feels to use); UI = the interface (what it looks like) |
| Wireframe | Prototype | Wireframe = structure only (low-fidelity); Prototype = functional model for testing (higher fidelity) |
| SEO keyword | Alt text | Keyword = helps search engines find a page; Alt text = helps screen readers describe an image to users |
| Template | Brand kit | Template = pre-designed layout; Brand kit = stored brand elements (colors/fonts/logo) |

2. Why does a designer create a wireframe BEFORE designing the final layout?
3. What is an alt tag, and why does it matter for both SEO and accessibility?
