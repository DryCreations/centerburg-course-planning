# Quiz: Multimedia Tools, UX/UI & Content Strategy

## Questions

| # | Question | A | B | C | D | Answer |
|---|----------|---|---|---|---|--------|
| 1 | What is the primary purpose of a wireframe? | To show the final color and font choices for a design | To map the structure and placement of content elements before adding visual design | To test a design with real users | To present the final product to a client | B |
| 2 | Which of the following describes UX (User Experience)? | The visual design of interface elements like buttons and menus | The overall quality of the interaction — how easy, efficient, and satisfying it is to use a product | The programming behind a website | The SEO ranking of a page | B |
| 3 | What does "alt text" provide when added to an image on a website? | A clickable thumbnail link | A text description of the image that screen readers use for visually impaired users, and that search engines index | A larger preview on hover | An animated caption | B |
| 4 | A Call to Action (CTA) is most effective when it: | Uses the same visual weight as body text | Is vague so users can interpret it independently | Is clear, action-oriented, and visually prominent — tells the user exactly what to do next | Links to an external site | C |
| 5 | Responsive design is important because: | It is only required for e-commerce sites | Users access websites from many different screen sizes — a responsive design adapts to each without breaking the layout | It is required only for government sites | It replaces the need for SEO | B |
| 6 | What is the UX Design Process? | Sketch → Render → Export → Publish | Click → Code → Launch → Monitor | Discover → Define → Ideate → Prototype → Test → Implement | Design → Approve → Delete → Redo | C |
| 7 | A template in design production is useful primarily because: | Templates automatically write the copy for you | Templates provide a pre-designed structural layout that can be customized — reducing setup time while maintaining layout quality | Templates cannot be edited | Templates require an additional subscription | B |
| 8 | A "keyword" in SEO is: | The password to a website's CMS | A word or phrase used in page content that matches user search queries — improving how often the page appears in search results | The brand name of a company | The alt text of an image | B |
| 9 | **[HOT]** A student builds a beautiful one-page website but doesn't add any alt text to her images. What two problems does this create? | None — alt text is optional for student projects | The website looks different in dark mode | It hurts SEO (search engines can't index image content) and it makes the site inaccessible to visually impaired users who rely on screen readers | The images load slower | C |
| 10 | Journey mapping in UX design helps designers: | Choose color palettes | Visualize the steps a user takes to reach a goal — revealing friction points where the experience breaks down | Select font pairings | Write marketing copy | B |
| 11 | **[HOT]** A website has an identical full horizontal navigation menu on both mobile and desktop. On mobile, what usability problem will users experience? | No problem — horizontal menus work everywhere | The menu will overlap the content on small screens, making navigation difficult and the page unusable on phones — responsive design requires a mobile-adapted navigation pattern | The fonts will change automatically | The images will disappear | B |
| 12 | A UX/UI designer's skills are most directly applicable to which type of project? | Commercial print brochures | Musical composition | Interactive web and app design — including navigation systems, wireframes, and user flow | Physical product manufacturing | C |
| 13 | A "stakeholder review" in the design process is: | When a developer reviews code | Presenting a design draft to the client or team to get feedback and approval before final production | The designer reviewing their own work | A legal review of IP rights | B |
| 14 | **[HOT]** A designer creates a one-page website for a new brand. A client review reveals: the CTA is buried at the bottom, there's no navigation, and images have no alt text. Which of these is a UX issue, which is an SEO issue, and which is an accessibility issue? | CTA = accessibility; navigation = SEO; alt text = UX | CTA = UX (user can't easily take action); navigation = UX (user can't move around); alt text = both SEO and accessibility | All three are only SEO issues | None of these are design issues | B |
