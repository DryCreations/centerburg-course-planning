## Quick-Reference Terms (Most Tested)

| Term | One-Line Definition |
|------|--------------------|
| Vector | Math-based; scales infinitely without quality loss |
| Raster | Pixel-based; quality degrades when scaled up |
| 300 DPI | Minimum resolution for print |
| 72 PPI | Standard resolution for web |
| CMYK | Print color mode (Cyan, Magenta, Yellow, Black) |
| RGB | Screen color mode (Red, Green, Blue) |
| Bleed | Extra design area past trim line for print |
| Kerning | Space between two specific characters |
| Leading | Vertical space between lines of text |
| Depth of field | Range of sharp focus in a photo; controlled by aperture |
| Wireframe | Low-fidelity layout sketch before full design |
| CTA | Action prompt ("Sign Up," "Buy Now") |
| Alt text | Image description for accessibility + SEO |
| WCAG 4.5:1 | Minimum color contrast for normal body text |
| QR code | Scannable code linking print to digital content |
| PDF | Portable format preserving layout for sharing/print |
| Brand kit | Pre-set of approved colors, fonts, and logo files for consistent use across all projects |
| Content calendar | Schedule mapping posts per platform per week |
| Buyer persona | Semi-fictional ideal customer profile |
