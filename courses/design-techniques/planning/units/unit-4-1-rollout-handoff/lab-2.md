# Lab 2: Client Delivery Package

**Course:** Design Techniques (145095)
**Unit:** 4.1 — Rollout, Handoff & Professional Publishing
**Duration:** 4 days | **Weeks:** 28–29
**Tools Needed:** Adobe Express, all project files from Units 1.3–3.1

---

## Objective

By the end of this lab, students will be able to:

- Organize all brand assets into a logical, consistently named file structure
- Export a 3-page brand guidelines PDF a non-designer could follow
- Write plain-language training notes and compile a complete professional handoff package

---

## Background

When a project ends, a client needs to take ownership. This lab is about producing deliverables so polished and complete that your client could maintain their own brand without asking you a single question.

---

## Instructions

### Step 1 — Organize Your Files (Day 1)

Create a file structure with clearly named folders: `/01-logos`, `/02-colors-fonts`, `/03-production-files`, `/04-exports`, `/05-guidelines`. Move all your project files from Units 1.3–3.1 into the appropriate folders using consistent naming conventions (e.g., `clientname-logo-primary-color.png`).

### Step 2 — Build the Brand Guidelines PDF (Day 1–2)

Create a 3-page Express document: Page 1 = logo suite and usage rules; Page 2 = color palette and typography; Page 3 = usage examples (do/don't). Write all instructions for a non-designer — no design jargon. Export as PDF.

### Step 3 — Write Training Notes (Day 2)

Write a 1-page plain-language guide: how to update the website, how to make a social post using the brand kit, and how to request a file from the designer. Test it: could a non-designer follow these steps without asking for help?

### Step 4 — Complete the Deployment Checklist and Timeline (Day 3)

Build a pre-launch checklist (every item is ✓ or ✗ — no ambiguity). Then write a 4-week rollout timeline: who does what in each week, specific platforms and actions.

### Step 5 — Compile and Submit (Day 4)

Assemble all deliverables. Confirm your Express website URL is still live. Submit all links and exports. Add to portfolio as Artifact #11.
