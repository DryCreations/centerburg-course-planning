## Student Overview

### What Is This Unit About?

Typography is the backbone of all design communication. This unit covers everything from typographic measurement (points, picas, ems) to font pairing, spacing adjustments, and the construction of a professional brand style guide. The style guide you produce here will be referenced in almost every subsequent unit.

### What You'll Be Able to Do

By the end of this unit you will be able to:

- Specify type using professional measurements (points, picas, em units)
- Adjust kerning, tracking, and leading deliberately and explain the visual effect
- Pair typefaces using classification principles (serif, sans-serif, display)
- Build a complete brand style guide covering identity, color, typography, and usage rules

### Common Issues & Responses

- **Usage rules section is vague:** Require at least 2 "Do" and 2 "Don't" examples with visual evidence (show, not just tell).
- **CMYK values missing from color palette:** Remind students that professional style guides always include print specs even if the brand is digital-only.
- **Brand kit not applied to the document itself:** The style guide must demonstrate the brand system, not just describe it.

### Differentiation Notes

- **Students who need more support:** Provide a completed 2-section sample showing the cover and color palette sections as reference.
- **Students who finish early:** Extension in project.md — write a 1-paragraph rebrand rationale for a well-known brand.

### Assessment Notes

- Project uses the 1–4 look-for rubric. Walk the room during Weeks 6–7 work time. Key checkpoints: are spacing values specified (not just font names)? Does the tone of voice section have example copy?
- BPA-track students using the WSAP client should receive the same rubric — no separate grading for BPA vs. class prompt.
