# Vocabulary: Typography & Brand Style Guides

---

## Terms

| Term | Definition |
|------|------------|
| **Typography** | The art and technique of arranging type to make text readable, legible, and visually appealing |
| **Typeface (font family)** | A set of fonts sharing a common design — e.g., "Helvetica" is a typeface with Regular, Bold, Italic variants |
| **Serif** | A typeface with small finishing strokes (serifs) on letterforms — traditionally associated with formality and print (e.g., Times New Roman, Georgia) |
| **Sans-serif** | A typeface without serifs — clean, modern, often preferred for screens and digital use (e.g., Helvetica, Open Sans, Roboto) |
| **Point (pt)** | The standard unit for type size in print; 72 points = 1 inch |
| **Pica** | A typographic unit; 1 pica = 12 points = approximately 1/6 inch |
| **Em** | A relative typographic unit equal to the current font size — scalable, used in web CSS for proportional spacing |
| **Kerning** | The adjustment of space between two specific letterforms |
| **Tracking** | The uniform adjustment of spacing across an entire word, line, or block of text |
| **Leading** | The vertical space between lines of text (line spacing); pronounced "LEH-ding" — from the lead strips used in traditional typesetting |
| **Type hierarchy** | The visual system that organizes text by importance: H1 (largest, most prominent) → H2 → body text → captions |
| **Font pairing** | The selection of two (or more) complementary typefaces used together in a design — typically a display face for headings and a text face for body |
| **Brand identity** | The visible elements of a brand: colors, typography, logo, and imagery that create a consistent, recognizable experience |
| **Brand style guide** | A document specifying all brand standards: color palette with hex codes, typefaces and usage rules, logo variations, tone of voice, do’s and don’ts |
| **Brand kit** | A predefined, reusable set of brand assets — approved colors, fonts, and logo files — organized for consistent application across all projects |
| **Brand archetype** | A personality template for a brand based on universal characters (Hero, Caregiver, Creator, Rebel, etc.) — guides tone of voice and visual style |
| **UVP (Unique Value Proposition)** | The specific benefit that distinguishes a brand from competitors — the core message of brand positioning |
| **Brand recognition** | The ability of customers to identify a brand based solely on its visual or sonic elements (logo, color, typography) |

---

## Key Distinctions

| Term 1 | Term 2 | Key Difference |
|--------|--------|---------------|
| Kerning | Tracking | Kerning = space between two specific letters; Tracking = uniform spacing across a whole block of text |
| Leading | Tracking | Leading = vertical line spacing; Tracking = horizontal letter spacing |
| Serif | Sans-serif | Serif = traditional/formal/print; Sans-serif = modern/digital/clean |
| Brand kit | Brand style guide | Brand kit = pre-set of approved brand assets (colors/fonts/logos) saved digitally for reuse; Brand style guide = full written document with all brand rules |
