# Project: Brand Style Guide

**Course:** Design Techniques (145095)
**Unit:** 1.3 — Typography & Brand Style Guides
**Duration:** Weeks 6–7

---

## Overview

Design a brand style guide for a subject of your choice. The style guide is a reference document — it defines the visual rules for a brand (colors, fonts, logo, usage). Built entirely in Adobe Express with the brand kit configured and applied.

---

## Choose Your Subject

Pick **one** of the following:

- **A) Your own personal brand** — Use the brand kit you have already been building. This becomes the visual system for your portfolio website.
- **B) A fictional persona or made-up company** — Invent a brand from scratch.
- **C) A character from a show, movie, or game** with a distinct visual aesthetic — Most superheroes work well. Think about their color scheme, personality, and visual identity.
- **D) The BPA competition prompt** — Use the WSAP-assigned theme if you plan to compete.

> **Note:** Your teacher will share examples of real company style guides and a completed example before you begin.

---

## What You're Producing

A multi-page Adobe Express document that defines the visual and verbal rules for your chosen brand.

### Required Sections

| Section | Content Required |
|---------|----------------|
| **Cover** | Brand name, tagline, logo on brand background |
| **Brand Identity** | Brand personality adjectives (3–5); who this brand is for |
| **Logo / Mark** | Your logo or monogram; clearspace note |
| **Color Palette** | 2–5 colors with hex codes, names, and usage notes |
| **Typography** | Heading font + body font; specimens at multiple sizes; font weight and size used for each level |
| **Usage Rules** | "Do" + "Don't" examples (at least 2 of each) |

> **Font specifications:** Use the labels from Adobe Express — font size in **points (pt)**, **Letter spacing**, **Line spacing**. Note these in your typography section.

### Technical Requirements

- Built entirely in Adobe Express
- Brand kit configured (colors + fonts + logo) and applied throughout

## Standards & Rubric

Walk the room as students work. Ask students to point to evidence for each standard before scoring.

| Standard | Description | Look-For (Proficient = 3) | Beginning (1) | Developing (2) | Proficient (3) | Advanced (4) |
|----------|-------------|--------------------------|---------------|----------------|----------------|--------------|
| **7.5.2** | Mix font families | Two typefaces used with written pairing rationale | One font; no rationale | Two fonts but no rationale | Two fonts + rationale | Three fonts with hierarchy and usage context |
| **7.5.3** | Kerning, leading, tracking | Heading and body spacing values documented (pt or em) | No spacing values | One value noted | Both heading and body documented | All type roles have documented spacing values |
| **7.5.4** | Typeface selection | Both fonts classified (serif/sans/display) with usage recommendation | Fonts listed, no classification | Classified but no usage rec | Both classified + 1 usage rec per font | Classification + recommendation + rationale or source |
| **7.5.5** | Type style guide | All type roles defined (H1/H2/body/caption) with sizes and weights | 1–2 roles defined | Major headings only; body missing | All standard roles defined | All roles + visual do/don't usage examples |
| **AC PRO 1.3.a** | Brand identity + style guide | All 5 sections present (overview, logo, color, type, voice) | 1–2 sections | 3 sections | All 5 sections with full content | All 5 + extension section (motion, icon system, or pattern) |
| **AC PRO 1.3.b** | Brand recognition / UVP | Brand overview states UVP in 1–2 sentences | No overview | Overview present but no UVP | Overview + clear UVP | UVP + target audience + brand personality statement |
| **AC PRO 3.1.f** | Brand kit configured in Express | Colors, fonts, and logo mark all configured | Brand kit not set up | Colors or fonts only | All three elements configured | Brand kit applied + verified across at least 2 Express artifacts |

- [ ] All fonts have sizes + spacing values + serif/sans classification
- [ ] Brand kit configured in Express: colors, fonts, logo mark
- [ ] Submitted as Adobe Express shareable link
- [ ] Added to portfolio as Artifact #3

## Portfolio Note

The Brand Style Guide is Artifact #3. It is the most referenced document in the portfolio — every subsequent project traces back to this brand system. Update it if you make significant changes to your brand identity in Units 2–4.

## Extension Task

Write a 1-paragraph "rebrand rationale" for an existing well-known brand: why should they rebrand? What would you change in their style guide, and what strategic reason justifies each change? This is the kind of business thinking that separates a strong design portfolio from a technical one.
