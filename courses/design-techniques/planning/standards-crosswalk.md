# Standards Crosswalk — Design Techniques (145095) ↔ Adobe Express Credential (AC PRO)

This document maps each Adobe Certified Professional exam objective to the Ohio CTE Design Techniques competencies it aligns with, and vice versa. Use this to ensure course instruction covers both sets of requirements simultaneously.

---

## Reading This Document

- **Strong alignment** — the objectives overlap directly in content and skill
- **Partial alignment** — the CTE standard touches on the concept but the credential goes deeper (or vice versa)
- **Gap** — content required by one set of standards that has no match in the other; requires dedicated instruction

## Section C: Gap Summary

### Gaps in CTE standards that the credential requires (need new instruction):

1. **Digital marketing fundamentals** — 4 P's deep dive, promotional mix, marketing strategies (B2B/B2C), digital marketing types (AC PRO 1.1–1.2)
2. **Content marketing & advertising** — owned/earned/paid media, ad types, PPC/CPM (AC PRO 1.4)
3. **SEO & content optimization** — keywords, web crawlers, page rank, algorithms (AC PRO 1.5.a)
4. **Retargeting, remarketing, A/B testing** (AC PRO 1.5.c–d)
5. **Social media marketing** — automation, scheduling, monitoring (AC PRO 1.6)
6. **Express-specific features** — themes, templates library, PDF tools, QR codes, translate, Text to Template, post scheduling (AC PRO 3.1.e, 3.5, 3.6, 3.7, 4.3, 5.2.b)

### Gaps in credential that CTE requires (still need dedicated instruction):

1. **Photography** — camera operation, manual settings, lighting setup (CTE 7.9)
2. **Business operations** — financial management, budgeting, entrepreneurship (CTE 1.7–1.9)
3. **Project management** — formal troubleshooting, testing/acceptance, rollout (CTE 2.11–2.13)
4. **Equipment** — hardware selection and configuration (CTE 2.10)

## Section D: Integration Strategy

The strongest alignment is in **design principles, graphics, typography, color, content creation, and digital ethics** — these should be taught using Adobe Express as the primary tool so every lesson serves dual purpose.

**Recommended approach:**
- Use **Adobe Express** as the primary design tool for the course, building credential fluency through daily use
- Teach **digital marketing** (Domain 1) as the framing context for design projects — every project has an audience, a brand, and a distribution strategy
- Maintain **dedicated photography instruction** using cameras — Express is the editing/publishing layer, not a replacement for camera skills
- Keep **business/financial units** as-is — these CTE-only standards don't need Express integration
- Add **Express-specific features** (templates, libraries, PDF tools, scheduling) as embedded mini-lessons during project work rather than standalone units
