# The Repair Clinic

**Design Techniques | Unit 2.1 Photography | Week 9**

**Four photos. Each one is broken a different way. Fix them.**

Everyone is working the same four files, so when we compare at the end, the difference is your
decisions and nothing else.

## Competencies

**7.9.6** Edit photographs (e.g., color corrections, cropping, enhancements).

**7.4.7** Optimize and export graphics files for intended use.

**7.2.7** Select colors based on color theory and psychology.

---

## How this works

The four RAW files are in the class folder. **Copy them to your own folder first.** Do not edit in
place.

For each one, in this order:

1. **Diagnose it.** Say what is wrong before you touch a slider
2. **Fix it** with the smallest number of moves that works
3. **Export it** as a JPEG named `LastName_Fix1_01`, `LastName_Fix2_01`, and so on
4. **Answer the two questions** for that file

**You are being graded on the diagnosis**, not on whether the photo ends up pretty.

---

## File 1: Too dark

**1.** Before you move anything: is this photo too dark **everywhere**, or only in parts? How can you
tell?

**2.** Fix it. Which did you use, **Exposure** or **Shadows**, and why was the other one wrong?

---

## File 2: Wrong white balance

**3.** Which direction is the color cast, and what in the photo tells you? Name the object you used.

**4.** Fix it. Did the eyedropper get you there, or did you finish it by hand? **What Kelvin did you
land on?**

---

## File 3: Flat and lifeless

**5.** This photo is correctly exposed and still looks dead. **Why?** Say it in terms of where the darks
and the lights are.

**6.** Fix it. You are allowed **three** sliders. List which three, and the value for each.

---

## File 4: One color is wrong

**7.** Everything in this photo is fine except one color. Which one, and what is wrong with it?

**8.** Fix it **in the HSL panel**, not with global Saturation. **Why would the global slider have made
this worse?**

---

## Last question

**9.** Of the four, which was hardest to diagnose? Not hardest to fix. **Hardest to see.**

## Grading

**The diagnosis questions are the assignment:** 1, 3, 5, 7 and 9. A correct fix with no idea what was
wrong earns about half.

Questions 2, 6 and 8 are each asking the same thing in a different costume: **the right tool, not just a
tool that worked.**
