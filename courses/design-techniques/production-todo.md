# Design Techniques — Production To-Do List

Work through this list in order. Each phase feeds the next: templates are built first so exemplars can be made using the same templates, and assignments are updated last once you know exactly what templates exist.

**Legend:** 🟥 Must have before teaching | 🟧 High value | 🟨 Medium value | 🟩 Lower priority

---

## Suggested Work Order (Collapsed)

If you need a single sprint list without the breakdown, work in this sequence:

1. Build all Q1 templates (10 items)
2. Build Q1 exemplars (style guide → website, in that order)
3. Build Q2 templates (5 items)
4. Build Q2 exemplars (proposal/planning doc → campaign)
5. Build Q3 templates (9 items)
6. Build Q3 exemplars (refined campaign → business package)
7. Build Q4 templates (8 items)
8. Build Q4 exemplars (client handoff → capstone)
9. Do all assignment refinements at the end of each quarter, not all at once

> **Minimum viable set to start the school year:** Get-to-Know-You Form, Portfolio Starter Site, Infographic Template, Color Theory Template, Style Guide Scaffold, Wireframe Worksheet, and the Unit 1.3 Style Guide Exemplar. Everything else can be built in the weeks before you need it.
