## The numbers (memorize cold)

| | |
|---|---|
| Maximum altitude | **400 ft AGL**, or 400 ft above a structure when within 400 ft of it |
| Maximum groundspeed | **100 mph** (87 knots) |
| Minimum flight visibility | **3 statute miles** |
| Cloud clearance | **500 ft below, 2,000 ft horizontal** |
| Registration threshold | **0.55 lb** (250 g) |
| Certificate recurrency | **24 calendar months** |
| Minimum age | **16** |
| Accident report window | **10 calendar days** |
| Reportable property damage | **$500** or more, other than the aircraft |

## Regulations and certification

| Term | Meaning |
|---|---|
| **Part 107** | The FAA rules for commercial small UAS operation |
| **TRUST** | Free recreational safety test. Fun flying only, not commercial |
| **Remote pilot in command** | The person responsible for the safety and legality of the flight. Always |
| **sUAS** | Small unmanned aircraft system, under 55 lb |
| **VLOS** | Visual line of sight, with unaided vision. Binoculars do not count |
| **Visual observer** | A person who helps maintain awareness of the aircraft and airspace |
| **Waiver** | FAA permission to deviate from a specific Part 107 rule |
| **Authorization** | ATC permission to operate in controlled airspace |
| **LAANC** | Low Altitude Authorization and Notification Capability. Near real-time authorization up to a published grid ceiling |
| **TFR** | Temporary flight restriction |
| **NOTAM** | Notice to air missions |
| **Operations over people** | The categories governing flight over non-participants |

## Airspace

| Term | Meaning |
|---|---|
| **Class B** | Busiest airports. **Solid blue** on the chart |
| **Class C** | Mid-size towered airports. **Solid magenta** |
| **Class D** | Smaller towered airports. **Dashed blue** |
| **Class E** | Controlled, often starting at 700 or 1,200 AGL. **Dashed magenta** where it starts at the surface |
| **Class G** | Uncontrolled. **No ring at all.** It is a real answer |
| **Floor / ceiling** | The bottom and top of a block of airspace |
| **Stacked numbers** | Ceiling over floor, in **hundreds of feet MSL** |
| **SFC** | Surface |
| **MSL** | Above sea level |
| **AGL** | Above ground level. **Parentheses on a chart mean AGL** |
| **Sectional chart** | The aeronautical chart showing airspace, terrain, and obstructions |
| **Grid ceiling** | The altitude LAANC will approve for a given square |

## Chart symbols

| Term | Meaning |
|---|---|
| **Blue airport symbol** | Has an operating control tower |
| **Magenta airport symbol** | No operating control tower |
| **Obstruction** | Tower or structure. Height shown MSL, with AGL in parentheses |
| **Guy-wires** | Support cables anchoring a tower, extending well out from its base. Nearly invisible, and they take down drones |
| **Shaded magenta band** | Class E begins at 700 ft AGL |

## Weather

| Term | Meaning |
|---|---|
| **METAR** | Current observed weather at a station |
| **TAF** | Terminal aerodrome forecast |
| **Zulu time** | UTC. Ohio is UTC-4 in summer, UTC-5 in winter |
| **Ceiling** | The lowest broken or overcast layer |
| **Visibility** | How far you can see, in statute miles |
| **Density altitude** | Pressure altitude corrected for temperature. Affects performance |
| **Personal minimums** | The limits you set for yourself, tighter than the legal ones |
| **Go / no-go** | The decision, made with a named deciding number |

## The aircraft

| Term | Meaning |
|---|---|
| **Airframe** | The physical structure |
| **ESC** | Electronic speed controller |
| **IMU** | Inertial measurement unit: accelerometers and gyros |
| **GNSS** | Satellite positioning. GPS is one system |
| **Gimbal** | Stabilized camera mount |
| **Failsafe** | What the aircraft does automatically on loss of link |
| **RTH** | Return to home |
| **Payload** | Anything carried beyond the aircraft itself |
| **MTOW** | Maximum takeoff weight |

## Batteries

| Term | Meaning |
|---|---|
| **LiPo** | Lithium polymer |
| **S rating** | Cells in series. More cells, higher voltage |
| **mAh** | Capacity |
| **C rating** | How fast it can safely discharge |
| **Storage charge** | The partial charge a pack should sit at when not in use |
| **Puffed** | Swollen from internal gas. **Always retire** |
| **Thermal runaway** | Self-sustaining battery fire. Water does not put it out |

## Operations

| Term | Meaning |
|---|---|
| **Preflight** | The inspection before flight, said out loud item by item |
| **Flight log** | The record of each flight. No log, no insurance claim, and no resume |
| **Crew resource management** | Pilot, visual observer, and logger working as a team |
| **Translation** | Moving the aircraft without turning the nose |
| **Orientation** | Knowing which way the nose points. **Nose toward you, your left is its right** |

## The pairs people mix up

| | |
|---|---|
| **MSL vs. AGL** | Sea level vs. ground level. Parentheses mean AGL |
| **TRUST vs. Part 107** | Recreational vs. commercial. Not interchangeable |
| **Authorization vs. waiver** | Permission to enter airspace vs. permission to break a rule |
| **Class C vs. Class D** | Solid magenta vs. dashed blue |
| **500 / 2,000** | Cloud clearance. **Below is the smaller number** |
| **Ceiling (weather) vs. ceiling (airspace)** | Cloud layer vs. the top of a block of airspace |
