# Aviation UAS — BPA Competition Reference

**Course:** 177024 Aviation Unmanned Aircraft Systems
**See also:** [Master BPA Events Reference](../../../program/bpa/bpa-events-master.md)

> **Cross-course note:** Students may compete in any BPA event, not just the ones listed here. The master reference document lists all events. Events below are the strongest natural fits for Aviation UAS content and skills.

---

## Competition Pathway

```
School Competition (January)  →  Ohio State Conference (Feb/Mar)  →  NLC Nashville (May 6–10)
Virtual Events: skip qualifying entirely — register Dec 1, submit Jan 15
```

Advancing at each stage is the student's choice. The goal is always to build something worth competing with. See the [master document](../../../program/bpa/bpa-events-master.md) for full dates.

## Primary Events for Aviation UAS Students

### #555 Presentation Individual *(Recommended primary event)*

| | |
|---|---|
| **Format** | Individual |
| **Deliverable** | 5–7 minute multimedia presentation delivered live to judges + Q&A |
| **Division** | Secondary and Post-Secondary |
| **BPA Topic** | Assigned each year by WSAP |
| **Class Connection** | Unit 1.1 (Industry & Career) and Unit 2.3 (dedicated BPA project block) |
| **BPA vs. Class** | Class: career-in-aviation presentation. BPA: presentation on assigned WSAP topic. Both use the same slide-building and delivery skills. |
| **Why it fits** | Aviation UAS is not directly represented in BPA's technical events. Presentation Individual lets students channel their aviation knowledge into a professional product, applying Strand 1 (Leadership, Communication) and Strand 2 (Project documentation) competencies. |

---

### #560 Presentation Team *(Team alternate for #555)*

| | |
|---|---|
| **Format** | Team (2–3) |
| **Deliverable** | Same as #555 in team format |

| **Notes** | Good option when 2–3 aviation students want to collaborate on a single submission. |

### #505 Entrepreneurship *(Strong option — business track)*

| | |
|---|---|
| **Format** | Individual |
| **Deliverable** | Operating plan + organizational structure for a new small business; presented as a pitch to mock investors |
| **Class Connection** | Unit 4.3 (UAS Drone Services Business Capstone) |
| **BPA vs. Class** | Class capstone requires a full drone services business plan — this IS a BPA entry with additional polish. Students may use the class project directly. |
| **Why it fits** | Drone services startups are a legitimate and growing business sector. The capstone's deliverables (business plan, pricing, operations, pitch) map directly to Entrepreneurship requirements. |

---

### #420 Digital Media Production *(Creative option)*

| | |
|---|---|
| **Format** | Individual or Team (up to 3) |
| **Deliverable** | 1–2 min digital media production on assigned topic |
| **Class Connection** | Unit 3.2 (Flight Operations) or Unit 4.1 (GIS Mission) — students document a real or simulated UAS mission |
| **BPA vs. Class** | Class project is a mission log/analysis. BPA version: produce a polished 1–2 min video using flight footage, GIS visualizations, or animated diagrams. Extra post-production work required outside of class. |
| **Why it fits** | Bridges aviation content with digital media production. Good for students who want a technical + creative output. |

---

### #545 Prepared Speech *(Low-barrier option)*

| | |
|---|---|
| **Format** | Individual |
| **Deliverable** | Prepared and rehearsed 4–6 min oral presentation on any topic |
| **Class Connection** | Unit 1.1 (Career Landscape) |
| **Notes** | Students can present on any aviation topic they research in class (FAA regulations, commercial UAS applications, Part 107 career path, etc.). Minimal production overhead — good for students who want to participate without a large project. |
