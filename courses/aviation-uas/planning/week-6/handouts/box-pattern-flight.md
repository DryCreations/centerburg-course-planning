# The Box Pattern

**Aviation UAS, Week 6, Thursday.** Every pilot flies the same thing. Same pattern, same altitude, same
order. That is the point: it is reproducible, so you can compare one flight to the next and see whether you
are getting better.

---

## Before anyone flies

**The gate is the same as always, and it is not optional.**

- [ ] Current METAR pulled and read out loud
- [ ] Compared against your **personal minimums card**
- [ ] **Go or no-go call made, with the deciding number named**
- [ ] Airspace confirmed for this site
- [ ] Preflight walked, item by item, out loud
- [ ] Roles assigned: **Pilot**, **Visual Observer**, **Logger**
- [ ] Everyone else behind the spectator line

**No preflight, no flight.** A no-go is a real outcome and it is logged like any other.

---

## The pattern

```
           4 ---------------- 3
           |                  |
           |                  |
           |                  |
           |                  |
           1 ---------------- 2
           ^
        takeoff / landing pad
```

**Fly it in order: 1, 2, 3, 4, back to 1.**

| Step | What you do | Hold |
|------|-------------|------|
| **Takeoff** | Lift to **15 feet**, hold a steady hover over the pad | **5 seconds** |
| **Corner 1** | You are here. Nose pointed away from you, downfield | 5 seconds |
| **1 to 2** | Translate **right** using the right stick only. Nose does not turn | |
| **Corner 2** | Stop. Hold position | **5 seconds** |
| **2 to 3** | Translate **forward**, away from you. Right stick only | |
| **Corner 3** | Stop. Hold | **5 seconds** |
| **3 to 4** | Translate **left**. Right stick only | |
| **Corner 4** | Stop. Hold | **5 seconds** |
| **4 to 1** | Translate **back** toward you. Right stick only | |
| **Landing** | Return over the pad, hold, then descend and land **on the mark** | **5 seconds** before descending |

**Box size:** roughly 30 feet on a side, or whatever the site allows. **Altitude: 15 feet, the whole way.**

---

## The three things being judged

**1. Does the nose stay put?** This is a **roll and pitch** exercise. The right stick only. If you are yawing
around corners, you are flying a different pattern than everybody else.

**2. Do you actually stop?** A five second hold means the aircraft is **still**, not drifting. Stopping is
harder than moving and it is the skill that matters.

**3. Does the altitude hold?** 15 feet at corner 1 and 15 feet at corner 4. Watch for sinking during
translation, which is the most common thing to lose.

## While you are waiting

You are not spectating. **Pick one and do it:**

- **Watch the sticks.** Call out, quietly to yourself, what the pilot is about to do before they do it
- **Time the holds.** Are they actually five seconds?
- **Watch for yaw.** Does the nose stay put through all four corners?
- **Watch the altitude.** Does it sink during translation?

You are flying this next. Watching somebody else make a mistake is the cheapest way to learn it.

---

## If you finish the box

Only if the basic pattern was clean, and only if there is time.

1. **Fly it in reverse.** 1, 4, 3, 2, back to 1
2. **Fly it at 25 feet** instead of 15
3. **Add a yaw:** at each corner, rotate 90 degrees to face the next leg, then translate forward
4. **Fly a diagonal** across the box and back
