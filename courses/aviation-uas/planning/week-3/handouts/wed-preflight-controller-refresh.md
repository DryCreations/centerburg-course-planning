# Preflight & Controller Refresh + Finalize the Plan

**Aviation UAS · Week 3 · Wednesday Sep 2**

Today you lock in Friday's flight: **refresh the controller**, walk a **preflight**, and **finalize your group's
mission plan**. A lot of this is new, so take it slow and ask questions.

---

## Controller refresh (the sticks)

- **Left stick:** throttle (up/down = altitude) and yaw (left/right = the nose turns/spins).
- **Right stick:** pitch (forward/back = fly forward/back) and roll (left/right = slide side to side).
- Practice the callouts: "up," "yaw left," "forward," "roll right." Slow, smooth inputs. Small corrections.
- Know **Return to Home (RTH)** and how to stop/hover.

## Preflight walk-through (say each one out loud)

- [ ] **Batteries** charged (aircraft + controller)
- [ ] **Props** on tight and not cracked or chipped
- [ ] **Firmware / app** ready; aircraft connects to the controller
- [ ] **Footage card** in and cleared (space for Friday's clip)
- [ ] **Compass / calibration** if the app asks
- [ ] **Home point** set at launch
- [ ] **Area clear:** people, obstacles, and a spectator line
- [ ] **Weather** looks flyable (we do the real go/no-go Friday)

> The rule: **no preflight, no flight.** If any item fails, we fix it before we launch.

## Finalize the mission plan

Finish the [Mission Plan Worksheet](mission-plan-worksheet.md) with your group. It's "done" when:

- [ ] The **one primary shot** is decided (subject + the move + about 20–40 sec).
- [ ] The **airspace check** is done (class + whether authorization is needed).
- [ ] The **flight area** is marked (launch/land, boundary, spectator line).
- [ ] The **go/no-go limits** are written (wind, visibility, precip).
- [ ] **Roles and rotation** are set (pilot, visual observer, logger).

> Friday: real-weather go/no-go, fly the shot, offload the footage, log the flight. Today just make the plan
> solid and the preflight familiar.
