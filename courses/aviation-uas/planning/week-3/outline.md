## Weeks 1–2 recap (what actually ran)

TRUST certification, the four forces and an airspace lookup, then the **DJI RC controller and controls**
hands-on, and a **first flight** (up, forward, turn, group photo, zoom photo, Return to Home). Students were set
up on **Ohio DOT's free Part 107 online course** (LDAP accounts), though access can take 48h+. The WebXam
pretest, the full METAR lesson, and Quiz 1 were deferred to fold in here.

## Student Overview

### What Is This Week About?

You have flown once and you know the controller. This week you start the **Part 107 study course** that builds
toward the real certificate, connect that study to what you actually did on the sticks, and fly a second time.
Friday there is a quiz on everything so far.

### What You'll Be Able to Do

- Log into and work through the ODOT Part 107 course
- Read current weather and make a simple go/no-go call
- Fly the set sequence more confidently and log it
- Explain the four forces, airspace basics, and the core safety rules

## Teacher Reference

### Pacing Guide

| Day | Activity | Notes |
|-----|----------|-------|
| Mon | Post `vocab.md`. Whole-class review of Weeks 1–2. Log everyone into the **ODOT Part 107 course** and start Module 1. | **If ODOT access still isn't active:** run paper sectional/airspace study and the airspace-lookup review instead; start the course the day it comes online. |
| Tue | ODOT airspace + regulations module. Tie each concept back to our flight site (what class of airspace are we in, would we need authorization). | Keeps the online course concrete. |
| Wed | Read a **real current weather report** and make a group go/no-go call for a hypothetical flight; review the preflight checklist. | This is the deferred METAR content, in a practical form. |
| Thu | **Second flight**: the set sequence plus one added element (a short controlled square or a longer hover). Log it. **No-go fallback:** controls dry-run + battery care + more ODOT course. | Same gates as before: TRUST on file, controller quiz passed, safe weather. |
| Fri | **Cumulative quiz** (`quiz.md`), then wrap and preview. | Short, formative. |

### Assessment Notes

- Quiz is cumulative over Weeks 1–3: aerodynamics, airspace, weather basics, sUAS rules, preflight, controls,
  and safety. Formative (Assessments category).
- Flight-log evidence: preflight completed, the sequence flown safely, battery ended at a safe charge and
  logged.
