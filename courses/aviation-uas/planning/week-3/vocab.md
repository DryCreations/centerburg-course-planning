# Week 3 Vocabulary: Flight, Airspace & Rules (cumulative)

Posted Monday. Friday's quiz draws from these — everything from Weeks 1–3.

## Terms

| Term | Definition |
|------|------------|
| **Part 107** | The FAA rule set and remote pilot certificate for commercial small-drone operations. |
| **TRUST** | The Recreational UAS Safety Test; proves knowledge of the recreational safety rules. |
| **Four forces of flight** | Lift, weight, thrust, and drag. |
| **Yaw / pitch / roll** | Rotation about the vertical / lateral / longitudinal axes (nose turn / fwd-back / tilt side-to-side). |
| **Throttle** | Controls altitude (up and down). |
| **Controlled airspace** | Airspace where ATC service is provided; may require authorization to fly. |
| **Uncontrolled airspace** | Airspace where no one separates traffic; the pilot is responsible. |
| **LAANC** | The system that grants (often near-instant) authorization to fly in many controlled areas. |
| **Ceiling** | The maximum altitude allowed for a drone at a location. |
| **METAR** | A current aviation weather observation report. |
| **NOTAM** | A Notice to Air Missions: temporary hazards or restrictions affecting flight. |
| **Visual line of sight (VLOS)** | Keeping the aircraft in view with your own eyes, as required. |
| **Visual observer** | A crew member whose job is to watch the aircraft and airspace for hazards. |
| **Return to Home (RTH)** | The function that flies the drone back to its takeoff point automatically. |
| **Preflight inspection** | Checking the aircraft is airworthy before flight. |
| **Airworthy** | In a safe condition to fly. |
| **Registration** | Most drones over 0.55 lb must be registered with the FAA. |

## Key Distinctions

| Term 1 | Term 2 | Difference |
|--------|--------|------------|
| Part 107 | TRUST | Part 107 = commercial certificate; TRUST = recreational safety test |
| Controlled | Uncontrolled | Controlled = ATC/authorization may be required; uncontrolled = pilot is responsible |
| METAR | NOTAM | METAR = current weather; NOTAM = temporary hazards/restrictions |
| Yaw | Roll | Yaw = nose turns left/right; roll = tilts and slides side to side |
