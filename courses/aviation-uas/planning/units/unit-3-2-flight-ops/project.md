# Project: Flight Operations Portfolio

**Course:** Unmanned Aircraft (177024)
**Unit:** 3.2 — Flight Operations & Communication
**Duration:** Weeks 24–25 deliverable
**FAA Study Guide Reference:** Chapters 6, 7, 12

---

## Overview

Students compile a Flight Operations Portfolio that demonstrates their ability to plan, execute, and document a complete UAS mission meeting commercial operator standards. The portfolio has two components: a written flight package and an aerial photo/video product.

---

## Deliverable A: Written Flight Package

A professional document with the following sections:

### Section 1: Mission Overview (1 page)
- Mission purpose and objectives
- Date, time, location (GPS coordinates and written description)
- Client or use case (even if hypothetical)
- Aircraft used: DJI Mavic 3, registration number

### Section 2: Airspace & Authorization
- Airspace class at the mission site
- Authorization method used (LAANC, Class G self-authorization, etc.)
- NOTAM check results (screenshot from notams.faa.gov acceptable)
- TFR check results (screenshot from tfr.faa.gov)

### Section 3: Weather Brief
- METAR from nearest reporting station (decoded)
- TAF (if available)
- Go/No-Go decision table (from Unit 2.1 format):

| Factor | Value | Acceptable? |
|--------|-------|-------------|
| Wind | ___ kts | |
| Visibility | ___ SM | |
| Ceiling | ___ ft | |
| Precipitation | | |
| Temperature / Density Alt | | |
| AIRMET/SIGMET | | |
| Final Decision | **GO / NO-GO** | |

### Section 4: Aircraft Preflight Checklist
- Complete DJI Mavic 3 preflight checklist (completed and signed)
- Battery levels at departure: __%
- GPS satellites at takeoff: ___
- RTH altitude set to: ___ ft

### Section 5: Flight Log (one entry per flight conducted)
Use the standard flight log form from the lab. Minimum 2 flight log entries.

### Section 6: Post-Flight Inspection Notes
- Any anomalies observed
- Components requiring attention before next flight
- Battery level at landing

### Section 7: SRM Reflection (½ page)
- Describe one moment during your flight when you had to manage multiple tasks simultaneously (e.g., monitor aircraft, check airspace, communicate with observer)
- What CRM/SRM principle did you apply?
- What would you do differently next time?

---

## Deliverable B: Aerial Photo Product

Create one of the following using footage from your lab and portfolio flights:

**Option 1: Photo Package** — 8 polished aerial photographs
- 4 cardinal-direction shots of one building or landmark
- 4 creative composition shots (your choice)
- Each photo labeled with: altitude, direction, purpose

**Option 2: Showcase Reel** — 60–90 second video
- Opening wide shot, then mix of establishing and detail shots
- Smooth transitions between clips; no abrupt cuts
- Music is optional; must be royalty-free
- Brief text overlay stating location and mission date

## Rubric

| Category | Excellent (4) | Proficient (3) | Developing (2) | Beginning (1) |
|----------|--------------|---------------|----------------|---------------|
| **Airspace & Authorization** | Accurate, all checks documented with screenshots | Mostly accurate; minor missing detail | Authorization method unclear or missing one check | Authorization not discussed |
| **Weather Brief** | Correct METAR decode + full go/no-go table | METAR decoded; table partially complete | METAR present but not decoded; table absent | No weather brief |
| **Preflight Checklist** | Complete, signed, GPS and RTH values present | Mostly complete; 1–2 items missing | Partial; several items missing | Not completed |
| **Flight Log** | 2+ complete entries; all fields filled | 2 entries; 2–3 fields blank | 1 entry present | No log entries |
| **SRM Reflection** | Specific scenario; CRM principle named and applied; clear lesson | Specific scenario; CRM principle named but application vague | General statement without specific scenario | No reflection |
| **Aerial Product** | Technically and compositionally strong; labeled correctly | Good quality; labels present | Adequate quality; labels missing | Poor quality or not submitted |
| **Professional Format** | No errors; consistent headers; looks like a real operator document | 1–3 minor errors | Inconsistent; 4–6 errors | Unprofessional formatting |

**Total: 28 points**
