## Class Prompt

You are a licensed Part 107 Remote Pilot operating a drone services business. A new client has contacted you for a commercial UAS operation. Your job is to plan the entire operation from scratch and present it as a professional **mission planning package** — the same documentation you would file before a real paid flight.

This project synthesizes everything from Unit 1.3 (regulations), Unit 2.1 (weather), and Unit 2.2 (preflight procedures). This is the highest-weighted EOC outcome (7.11 = 14.58%) — mastery here directly raises your WebXam score.

---

## Mission Scenario (choose one)

**Mission A — Infrastructure Inspection**
Knox Electric Cooperative has hired you to photograph all 12 transmission towers along a 4-mile power line corridor in rural Knox County. The corridor passes within 1.5 miles of Knox County Airport. Some towers exceed 200 ft AGL. Flight planned for a weekday in August.

**Mission B — Construction Site Survey**
A real estate developer needs weekly photogrammetry mapping of an active construction site in a Columbus suburb. The site is 2.4 miles from Rickenbacker International (KLCK), which has Class D airspace. Flight planned for a Wednesday morning in September.

**Mission C — Agricultural Crop Health Mapping**
A 400-acre farm near Fredericktown, Ohio has contracted you for an NDVI mapping flight for crop health analysis. The farm is in Class G airspace, 6 miles from the nearest airport. Flight planned for a weekday morning in July.

## Deliverables

### Part 1: Written Mission Planning Package (Google Doc)

**Section 1 — Mission Overview (1 paragraph)**
- Client, mission type, aircraft (DJI Mavic 3), flight date and window, location

**Section 2 — Airspace Analysis**
- Airspace class at the flight location (identify with sectional chart reference)
- Authorization required: LAANC / waiver / none
- LAANC grid altitude available (if applicable; use B4UFLY)
- Special use airspace within 5 miles? (Restricted, MOA, Prohibited)
- TFR check: result from tfr.faa.gov
- NOTAM check: result from notams.faa.gov; list any relevant NOTAMs
- Your authorization documentation method

**Section 3 — Weather Brief**
*(Use skills from Unit 2.1 project — reuse the format)*
- Current or realistic METAR: full decode
- TAF summary for flight window
- AIRMET/SIGMET check
- Go/no-go decision with documented reasoning
- Weather risk mitigation (e.g., fly before a frontal system, monitor gusts)

**Section 4 — Aircraft Performance & Weight/Balance**
- Total aircraft weight: DJI Mavic 3 = 895 g (1.97 lbs)
- Payload attached (if any): camera, sensor, etc.
- Does total weight exceed 55 lbs? (No — state why this matters for Part 107)
- Density altitude estimate for your date/location
- Expected battery flight time given conditions (DJI Mavic 3 standard: 46 min; estimate reduction due to density altitude, wind, payload)
- How many battery cycles needed for this mission?

**Section 5 — Physical Preflight Checklist (DJI Mavic 3)**
Complete the full preflight inspection form (from Unit 2.2 lab). Check all boxes as if you are actually about to fly. Add notes for any considerations specific to your mission scenario.

**Section 6 — Flight Plan**
- Flight area boundary: describe or sketch (can use Felt or Google Maps screenshot)
- Maximum altitude: state the planned altitude ceiling and why
- RTH altitude: state the setting and the obstacle that drives it
- Visual observer: will you use a VO? Why or why not?
- Emergency landing zones: identify 2 emergency landing areas within the flight area

**Section 7 — Risk Assessment**

| Risk | Likelihood (L/M/H) | Consequence (L/M/H) | Mitigation |
|---|---|---|---|
| Weather deterioration during flight | | | |
| Aircraft GPS loss | | | |
| Battery failure mid-mission | | | |
| Bystander enters flight area | | | |
| Control link interference | | | |
| Wind exceeds aircraft limit | | | |

After the table, write a 2–3 sentence overall risk summary and state your go/no-go threshold (e.g., "I will abort the mission if wind exceeds 15 kts at any point during flight").

---

### Part 2: Mission Briefing (5–7 minutes, Week 15)

Present your mission planning package to the class as if you are briefing your crew before departure. You are the remote PIC.

Cover:
1. Mission overview and client needs (30 seconds)
2. Airspace status — are we authorized? Any TFRs/NOTAMs? (1–2 minutes)
3. Weather brief summary — go or no-go? Key factor? (1–2 minutes)
4. Aircraft status — battery plan, RTH altitude, any concerns? (1 minute)
5. Risk summary — the one risk you are most focused on managing today (1 minute)

Do not read from your document. Speak as a professional.

## Rubric

| Component | Full (4) | Partial (2) | None (0) |
|---|---|---|---|
| **Airspace Analysis** | Correct class; LAANC/waiver status accurate; TFR + NOTAM checked and documented | Mostly correct; one check missing or incorrect | Missing or incorrect class |
| **Weather Brief** | METAR decoded; TAF interpreted; AIRMET/SIGMET checked; go/no-go justified | Partially complete; decision not fully justified | Missing or no weather analysis |
| **Performance/W&B** | Density altitude calculated; battery estimate made; payload weight considered | Density altitude mentioned but not calculated; partial analysis | Missing |
| **Preflight Checklist** | All checklist items completed; any fail items noted and appropriate action documented | Most items checked; some sections blank | Missing |
| **Flight Plan** | Altitude, RTH, VO decision, emergency landing zones all documented | Most components present; some missing | Missing |
| **Risk Assessment** | 6 risks addressed; likelihood/consequence rated; mitigation specific; go/no-go threshold stated | Risks listed but not fully analyzed; mitigation vague | Missing |
| **Briefing Delivery** | 5–7 min; all 5 elements covered; not read verbatim; professional | Under/over time; some elements missing; partially read | Missing or completely read |
