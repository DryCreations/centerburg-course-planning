# Vocabulary: GIS, Remote Sensing & Photogrammetry

**Course:** Unmanned Aircraft (177024)
**Unit:** 4.1 — GIS, Remote Sensing & Photogrammetry
**Weeks:** 28–30
**Standards Focus:** 7.10.1–7.10.11

| Term | Definition | Related Standard | DOK |
|------|-----------|-----------------|-----|
| **Geographic Information System (GIS)** | A computer-based system for capturing, storing, analyzing, and displaying spatially referenced data; combines maps with attribute databases | 7.10.1 | 2 |
| **Remote Sensing** | The collection of data about an object or area without physical contact; UAS imagery is a form of remote sensing | 7.10.2 | 2 |
| **Orthomosaic** | A geometrically corrected aerial image mosaic in which all pixels represent accurate horizontal distances; produced by photogrammetry software (e.g., WebODM) by stitching overlapping images | 7.10.5 | 2 |
| **Photogrammetry** | The science of making measurements from photographs; UAS photogrammetry uses overlapping aerial images to produce 3D models, elevation data, and orthomosaics | 7.10.5 | 3 |
| **Point Cloud** | A 3D data set of georeferenced points generated by photogrammetry or LiDAR; used to create digital surface models and 3D visualizations | 7.10.5 | 2 |
| **Digital Elevation Model (DEM)** | A raster data layer representing ground surface elevation; produced by photogrammetry from overlapping images or LiDAR | 7.10.6 | 2 |
| **Raster Data** | Spatial data stored as a grid of pixels (cells), each with a value; aerial imagery and DEMs are raster data types | 7.10.3 | 1 |
| **Vector Data** | Spatial data represented as geometric shapes (points, lines, polygons) with associated attributes; roads, property lines, and survey boundaries are vector data | 7.10.3 | 1 |
| **Attribute Table** | The database table linked to a GIS vector layer; each row is a feature (e.g., a building), and columns contain data values (e.g., height, owner, year built) | 7.10.4 | 2 |
| **Layer** | A single thematic dataset in a GIS; layers are stacked to build a map (e.g., roads layer, imagery layer, parcel boundary layer) | 7.10.1 | 1 |
| **Ground Control Point (GCP)** | A precisely located, GPS-surveyed marker placed on the ground before a UAS flight; used in photogrammetry processing to improve spatial accuracy | 7.10.5 | 2 |
| **Overlap (Image)** | The percentage of shared area between adjacent images in an aerial survey; 80% frontal overlap and 60% sidelap is a common standard for photogrammetry | 7.10.5 | 2 |
| **Coordinate System** | A mathematical framework for defining location on the earth's surface; most UAS data uses WGS 84 (GPS standard) or a state plane coordinate system | 7.10.7 | 2 |
| **WebODM** | Open-source photogrammetry processing software that converts overlapping UAS images into orthomosaics, DEMs, and 3D point clouds | 7.10.5 | 1 |
| **QGIS** | Free, open-source desktop GIS application for analyzing, visualizing, and editing spatial data layers | 7.10.1 | 1 |
| **Felt** | A collaborative, web-based GIS mapping platform for creating and sharing maps; used for team GIS projects in this course | 7.10.1 | 1 |
| **Spatial Analysis** | The process of examining patterns, relationships, and trends in geographic data using GIS tools; examples: buffer analysis, overlay analysis, proximity analysis | 7.10.8 | 3 |
| **Ground Sampling Distance (GSD)** | The real-world size of one pixel in an aerial image; smaller GSD = higher resolution; GSD depends on altitude and camera sensor | 7.10.5 | 2 |
| **Mission Planning (Survey)** | Pre-flight configuration of flight altitude, image overlap, and ground coverage for a photogrammetry mission; typically done with DJI Pilot 2 or a mission planning app | 7.10.5 | 2 |
| **LiDAR** | Light Detection and Ranging — a remote sensing technology that uses laser pulses to measure distances; generates highly accurate 3D point clouds; used in professional UAS survey applications | 7.10.2 | 2 |
