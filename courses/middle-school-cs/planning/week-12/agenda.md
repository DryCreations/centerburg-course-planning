## New vocab

- **Codeblocks:** Tinkercad's way to build 3D models with block code
- **Block:** one instruction you snap into your code
- **Sequence:** the order the blocks run, top to bottom
- **Run:** play your code to see what it builds
- **Loop:** a block that repeats the blocks inside it
- **Counter:** a number that goes up by one each time the loop repeats
- **Variable:** a named number you can change in one place
- **Debug:** find and fix what is wrong in your code
