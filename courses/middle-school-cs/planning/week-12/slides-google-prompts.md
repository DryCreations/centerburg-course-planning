# Middle School CS Week 12: Daily Slides

**Teacher-only.** One slide per day. Paste into Google Slides' "Help me create a presentation," or
type it in. No standards slide needed for MS CS, so each slide names the focus.

**Test Codeblocks before Tuesday.** Run the handout's snowman, staircase, and tower yourself so you
know where each block lives (Shapes, Modify, Control, Math, Variables).

