# Codeblocks: Build With Code

**Middle School CS | Tuesday to Thursday**

In Tinkercad, click **Create**, then **Codeblocks.** Start a new blank design each day and name it
`LastName_Code1`, `Code2`, and `Code3`. Click **Run** (the play button) to watch your code build.

---

## Tuesday: Sequence

Code runs **top to bottom**, one block at a time.

1. Drag in a block to **add a sphere.** Run it
2. Add a smaller sphere and **move** it up so it sits on the first one
3. Add the smallest sphere and move it up again. You have a snowman
4. Add a cone for a nose and move it into place

**1.** Drag the nose blocks to the very top of your code and run it. What changed, and why?

**2.** Fix it, then add one more detail of your own, like a hat.

## Wednesday: Loops

A **repeat** block runs the blocks inside it again and again. A **count with** block does the same,
with a counter that goes up by one each time.

1. Use **count with** from 1 to 10
2. Inside it, add a box, then **move** it by the counter times 25 on the x axis. You get a row of 10
3. Change the row into a **staircase:** also move each box up by the counter times 10

**3.** How many blocks would the staircase take without a loop?

**4.** Change one number to make 20 steps. Which number did you change?

## Thursday: Variables

A **variable** is a named number. Change it once and every block that uses it changes.

1. Make a variable called `size`. Set it to 20
2. Build a tower: a loop that stacks boxes, using `size` for each box's width and for how far each box
   moves up
3. Change `size` to 10, then to 40. Run it each time

**5.** What happened to the tower when you changed `size`?

**6.** Where else could a variable save you time in a design?

## Done early?

Build a pattern that would take forever by hand: a spiral, a ring of shapes, or a castle wall. Use a
loop and at least one variable.

## Graded on

Answers to all six questions, and your three designs saved with the right names.
