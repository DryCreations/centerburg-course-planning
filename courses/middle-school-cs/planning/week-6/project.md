## What makes it good, not just done

- **No copied blocks.** Six spawn blocks in a row is a loop you did not use
- **It ends.** A game that runs forever with no win and no loss is not finished
- **It stays fast.** Everything you create has to be destroyed eventually
- **Somebody else can play it** without you explaining the controls
