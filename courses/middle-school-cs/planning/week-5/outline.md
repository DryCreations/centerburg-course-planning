# Week 5: Loops and Star Catcher: Outline

**Course:** Middle School CS | **Week:** 5 | **Dates:** Mon Sep 14 to Fri Sep 18

> **New project, new idea: loops.** Last week you placed every item in your maze by hand. This week you learn
> the block that does it for you, and build a brand new game around it.

---

## What This Week Covers

**Star Catcher.** Stars fall from the top, you catch them at the bottom. Every part of it is built with a
different kind of loop.

## Student Overview

### What You'll Be Able to Do

- Explain what a loop is and why it beats copying blocks
- Use `repeat` to run code a set number of times
- Use `for index` and use the count inside the loop
- Use `forever` to keep something running for the whole game
- Use `while` and explain how to keep it from freezing the game
- Nest one loop inside another to spawn a wave
