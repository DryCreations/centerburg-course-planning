# Week 5: Loops and Star Catcher: Outline

**Course:** Middle School CS | **Week:** 5 | **Dates:** Mon Sep 14 to Fri Sep 18

> **New project, new ideas: loops and modulo.** Last week you placed every item in your maze by hand. This
> week you learn the blocks that do it for you, and build a brand new game around them.

---

## What This Week Covers

**Star Catcher.** Stars fall from the top, you catch them at the bottom. Every part of it is built with a
different kind of loop.

## Student Overview

### What You'll Be Able to Do

- Explain what a loop is and why it beats copying blocks
- Read a `while` loop out loud as a sentence, and trace how many times it runs
- Explain what makes a loop infinite, and how to avoid it
- Use `repeat` to run code a set number of times
- Use `for index` and use the count for spacing, speed, or color
- Use the `remainder` block to make something happen every Nth time
- Use `forever` to keep something running for the whole game
- Nest one loop inside another to spawn a wave
