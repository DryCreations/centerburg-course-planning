## What makes it good, not just done

- **No copied blocks.** If you have the same three blocks five times in a row, that is a loop you did not use.
- **It ends.** A game that runs forever with no win and no loss is not finished.
- **It stays fast.** If stars are never destroyed they pile up and the game crawls.
- **Someone else can play it** without you explaining the controls.
