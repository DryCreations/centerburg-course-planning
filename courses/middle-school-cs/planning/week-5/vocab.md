# Week 5 Vocabulary: Loops

| Term | Definition |
|------|------------|
| **Loop** | A block that runs the code inside it more than once. |
| **Iteration** | One single pass through a loop. |
| **repeat** | A loop that runs an exact number of times, then stops. |
| **for index** | A counting loop. It runs a set number of times and tells you which pass you are on. |
| **index** | The number the `for` loop is currently on. It starts at 0. |
| **while** | A loop that keeps going as long as a condition is true. |
| **forever** | A loop that never stops while the game is running. |
| **Nested loop** | A loop inside another loop. |
| **Infinite loop** | A loop that never ends because nothing makes its condition false. It freezes the program. |
| **Condition** | The true-or-false check a `while` loop tests before every pass. |
| **Modulo / remainder** | What is left over after dividing. `remainder of 7 ÷ 3` is 1. |
| **Multiple** | A number that divides evenly. `remainder of N ÷ 5 = 0` is true when N is a multiple of 5. |
| **Trace** | Working through code by hand, one pass at a time, to see what it does. |

## Carried forward

| Term | Definition |
|------|------------|
| **Variable** | A named container holding a value that can change. |
| **Counter** | A variable used to count how many times something happened. |
| **Conditional (if)** | A block that runs something only when a condition is true. |
| **Sprite** | An image in the game that code can move and react to. |
| **Event** | Something that triggers code to run, like a button press or an overlap. |

## Review Questions

1. What is a loop, and why is it better than copying the same blocks ten times?
2. `for index from 0 to 4` runs how many times? Why does that surprise people?
3. What can `for index` do that `repeat` cannot?
4. When would you use `while` instead of `repeat`?
5. What makes a loop infinite, and what does that do to your game?
6. What is a nested loop, and what did you use one for in Star Catcher?
7. What is `remainder of 12 ÷ 5`, and why?
8. Write the condition for "every 4th star."
9. How many times does this run: `set x to 10`, `while x > 10: change x by -1`? Why?
