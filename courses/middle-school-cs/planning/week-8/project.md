# Final Project: Your Own Game

**Middle School CS | Planned Week 8, built Week 9**

**You design it. You build it.** It is the last project of the quarter.

---

## This week you plan. Next week you build.

**No code until your plan is approved.** A plan takes twenty minutes. A game built without one takes a
week and does not work.

---

## What it has to include

**Six things.** Your game can be anything, as long as all six are in it.

- [ ] **A list**, used for something that matters
- [ ] **A loop**
- [ ] **A conditional** (`if`, or `if / else`)
- [ ] **A variable** that changes during play
- [ ] **A way to win**
- [ ] **A way to lose**

**That is the grade.** Not how impressive it is, not how pretty. Six things, working.

> **Small and finished beats big and broken.** Every single time.

---

## The plan, due this week

Answer all of it before you write any code.

**1. What is your game?** One sentence. If it takes you a paragraph, it is too big.

**2. What does the player control?** What buttons do what?

**3. What is the player trying to do?**

**4. How do they win?** Be specific. A number, a condition, something checkable.

**5. How do they lose?** Same.

**6. What is your list for?** Name it, and say what goes in it. This is the question most people get
stuck on, so think about it properly.

**7. What is your variable for?** Name it, and say what changes it.

**8. What sprites do you need?** List them, and say what each one does.

**9. Draw the screen.** On paper. Where things start, roughly. Stick figures and boxes are fine.

**10. What is the first thing you will build?** The smallest piece that does anything at all.

## Ideas, if you need one

**You do not have to use these.**

| Idea | What the list holds |
|---|---|
| **Recipe game** | Ingredients you have collected. Win when you have the right set |
| **Memory / pattern** | The sequence the game showed you. Lose when the player's order does not match |
| **Inventory adventure** | Items you are carrying. Doors open only if you have the right thing |
| **Wave defender** | How many enemies each wave holds, so difficulty is just a list of numbers |
| **Fishing / collecting** | What you have caught. Win on variety, not quantity |
| **Deliveries** | Orders waiting to be filled. Each delivery removes one from the list |
| **Quiz game** | Questions, and a second list of answers at matching positions |
| **Maze with keys** | Keys collected. The exit checks whether you have them all |

## Scope, honestly

**You have one week to build it.** That is about four class periods.

| Realistic | Not realistic |
|---|---|
| One screen, one mechanic, done well | Multiple levels with cutscenes |
| Four or five sprite kinds | Twenty different enemies |
| Win and lose that both work | A save system, a shop, a story |
| A list of six things | A list of three hundred things |

**If your plan has more than six required features in it, cut something now** rather than running out of
time next Thursday.
