## The six requirements

1. A **list** the game uses to make a decision
2. A **for or while loop** that runs a set number of times. Not `forever`
3. An **if** that can go either way
4. A **variable** that changes during play
5. A way to **win**
6. A way to **lose**

**Test:** if you remove a piece and the game plays the same, that piece does not count.
