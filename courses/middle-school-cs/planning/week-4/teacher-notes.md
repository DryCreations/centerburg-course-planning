# Week 4 Teacher Notes: Middle School CS

Teacher-facing pacing for Week 4. Student doc is `outline.md`; the lab is `project.md`; the quiz (30-question
bank, cut to 20) is `quiz.md` and `quiz-bank.csv`.

## Pacing Guide

| Day | Activity | Notes |
|-----|----------|-------|
| Tue | **Quiz.** Same silent, quiz-tab-only rules as the other classes: as-you-come-in slide, then a Do Now to take it. | Held over from last week's plan; this is their first real quiz. |
| Wed | Bell ringer. Intro loops: a `repeat 4 times` loop and a `forever` loop side by side. Show a forever loop moving a sprite back and forth. | Contrast loops with if statements explicitly: a loop repeats, a conditional decides. |
| Thu | Bell ringer. Put an if statement inside a forever loop (for example, spawn an item every loop, then use pick random plus an if to decide good or bad). Assign the Loop It lab. | This is the actual target skill: loop plus if together. |
| Fri | Bell ringer. Work time on the lab. | Redo is allowed anytime per the course's grading model. |

## Assessment Notes

- Quiz is summative under Checkpoints (25% of the grade per `grading-and-categories.md`).
- Lab is graded on the class project rubric: works, can explain it, kept going, turned in right.

## Bell ringer bank

Build new loop-trace bell ringers this week, for example: `repeat 3 times: change score by 2` -> what is
score? (+6 from 0). Walk it line by line, same pattern as the if-statement bell ringers from Week 3.
