# Week 4 Vocabulary: Tile Maps & Collision

Posted Wednesday. Friday's quiz covers **if statements and everything before**, not these terms, but you will
need them for the Maze Collector lab.

## This week's terms

| Term | Definition |
|------|------------|
| **Tile map** | A game world built from a grid of small squares. Most 2D games use one. |
| **Tile** | One square of that grid. |
| **Wall** | A tile marked as solid, so sprites cannot move through it. |
| **Collision** | What happens when two things in a game touch, like a player hitting a wall. |
| **Counter** | A variable used to count how many times something happened. |

## Carried from Weeks 1 to 3 (this IS on Friday's quiz)

| Term | Definition |
|------|------------|
| **Variable** | A named container that holds a value. |
| **Conditional (if)** | Code that decides: if this is true, do that. |
| **Overlap** | The event that runs when two sprites touch. |
| **Sprite** | A thing in your game that moves or gets touched. |
| **Event** | Something that starts code running. |
