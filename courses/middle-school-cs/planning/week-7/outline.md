**Course:** Middle School CS | **Week:** 7 | **Dates:** Mon Sep 28 to Fri Oct 2

> **Monday is review.** Then one new idea for the week: a **list**, which is a variable that holds many
> things instead of one.

---

## What This Week Covers

You have variables that hold **one** thing. A list holds **many**, in order, and you can ask it
questions: how many, which one, is this in it, pick a random one.

It is the last big structure before things get abstract, and it makes a lot of things you already wanted
to do suddenly easy.

## What You'll Be Able to Do

- Explain the difference between a variable and a list
- Create a list, add items, and get an item by its position
- Use `length of list` to loop through a list of any size
- Pick a random item from a list
- Say why item number 0 is the first one
