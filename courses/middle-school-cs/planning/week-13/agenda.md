## What is on the quiz

**Quiz: Friday, Nov 20.** It covers last week and this week:

- **Sequence:** code runs top to bottom, so order matters
- **Loops:** repeat and count with. A loop that counts 1 to 5 runs 5 times
- **Counter:** the number that goes up each time a loop runs. Moving `i × 20` puts shapes in a row
- **Nested loops:** a loop inside a loop. 3 rows of 4 makes 12 shapes
- **Variables:** a named number. Change it once and everything that uses it changes
- **Axes:** x is left and right, y is front and back, z is up and down
- **Debug:** find and fix what is wrong
- **Submitting:** a screenshot and a working link

## Practice problems

1. A loop counts `i` from 1 to 6 and adds a box each time. How many boxes?
2. Each box moves `i × 20` on the x axis. Where does box 3 end up?
3. An outer loop counts 1 to 3. The inner loop counts 1 to 4. How many shapes?
4. A variable `size` is 10. You change it to 30. What happens to the model?
5. You want a stack of boxes going up. Which axis do you move them on?
6. All your boxes land in the same spot. What is the most likely bug?
7. What two things do you turn in for every Tinkercad assignment?

## New vocab

- **Nested loop:** a loop inside another loop
- **Grid:** shapes in rows and columns
- **Random:** a number the computer picks for you, different each run
