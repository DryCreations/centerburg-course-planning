# Week 5 Vocabulary: Pre-Production and Screenplay Format

## Screenplay format

| Term | Definition |
|------|------------|
| **Screenplay format** | The industry-standard script layout: scene headings, action, character names, dialogue. |
| **Scene heading (slugline)** | The all-caps line naming interior or exterior, the location, and the time. `INT. HALLWAY - MORNING` |
| **INT. / EXT.** | Interior or exterior. Whether the scene is inside or outside. |
| **Action** | Present-tense description of only what we can see and hear. |
| **Dialogue** | The words a character speaks, set under their name in a narrower column. |
| **Parenthetical** | A short note on how a line is delivered. Used rarely. |
| **Transition** | An instruction like `CUT TO:` or `FADE OUT.` Modern scripts use very few. |
| **CONT'D** | Marks that the same character is continuing to speak after an action line. |
| **Courier** | The typeface screenplays use, because in it one page runs about one minute of screen time. |

## Pre-production documents

| Term | Definition |
|------|------------|
| **Two column (A/V) script** | Video on the left, audio on the right. Used for documentary, news, promos, and PSAs. |
| **Storyboard** | One drawn panel per shot, showing framing and movement. |
| **Shot list** | A table of every shot to get, in shooting order, with type, location, and equipment. |
| **Call sheet** | The document telling the crew where to be, when, and with what. |
| **Production schedule** | What gets filmed on which day. |
| **Coverage** | Shooting a scene from enough angles to have options in the edit. |
| **Continuity** | Keeping details consistent across shots so the edit does not jump. |
| **Table read** | Reading the script out loud with people taking parts, to hear what works. |

## Review Questions

5. What is the difference between coverage and continuity?
