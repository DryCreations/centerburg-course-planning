# Building a Production Schedule

**Video & Sound, Week 5.** A production schedule answers one question: **who is shooting what, where, and
when.** Without one, three groups show up needing the same camera in the same room at the same time and
nobody gets anything.

---

## What we are working with

| Resource | Count |
|----------|-------|
| **Shooting cameras** (manual video: T4i, T5, T6) | **3** |
| Utility camera (T3, auto only, behind the scenes and stills) | 1 |
| Class periods before rough footage is due | Thursday, then next week |

**Three cameras means three groups shoot at a time.** Everything below exists to make that work.

---

## Part 1: Break your script into shoot blocks

A **shoot block** is everything you can film **in one place, in one session, without moving.**

Go through your script scene by scene and sort every shot by **location**, not by story order.

| Block | Location | Shots from the script | Estimated time |
|-------|----------|----------------------|----------------|
| A | | | |
| B | | | |
| C | | | |

> **Story order is for the audience. Location order is for the crew.** You shoot everything in the hallway
> while you are standing in the hallway, no matter where those shots land in the finished video.

---

## Part 2: Estimate honestly

This is the part everyone gets wrong. **Estimate each shot, then check your estimate against the list
below.**

| Shot type | Realistic time, including setup |
|-----------|--------------------------------|
| Simple static shot, one subject, no dialogue | **5 to 8 minutes** |
| Shot with dialogue, two or three takes | **10 to 15 minutes** |
| Shot with movement (walking, camera moving) | **12 to 20 minutes** |
| Any shot needing a specific location to be empty | **add 10 minutes** of waiting |
| Moving the whole setup to a new location | **10 minutes** |
| Room tone at a location | **2 minutes**, do not skip it |

**A 90 second video is usually 8 to 12 shots. That is two to four hours of shooting**, spread across several
sessions. If your estimate came out to 30 minutes total, it is wrong.

### The rule that makes estimates useful

> **Take your honest estimate and add half again.** If you think a block is 20 minutes, schedule 30.

You will lose time to things you cannot predict: a bell, a door, a group walking through, a battery, a shot
that looked fine until you played it back.

---

## Part 3: Sort by where it can be shot

| Category | What it means | When |
|----------|---------------|------|
| **IN ROOM** | Can be filmed inside this classroom | **Thursday** |
| **IN BUILDING** | Needs a hallway, gym, cafeteria, commons, stairwell | **Next week** |
| **OUTSIDE** | Needs the parking lot, field, or outdoors | **Next week** |
| **PROBLEM** | Needs something we do not have or cannot get to | **Rewrite it** |

**Anything in the PROBLEM row gets solved now, not on shoot day.** Either rewrite the shot so it can happen
somewhere you can actually go, or cut it.

> **Thursday is an in-room shoot day.** Every group needs at least two shots that can be filmed inside this
> classroom, so plan for that specifically. If your script has nothing that works in a classroom, find the
> shot that could, or add one.

---

## Part 4: The shared schedule

Your group does not schedule alone. **All three groups fill this in together**, because there are three
cameras and one room.

### Thursday, in room

| Time block | Group 1 | Group 2 | Group 3 |
|------------|---------|---------|---------|
| First 15 min | Setup + checklist | Setup + checklist | Setup + checklist |
| | | | |
| | | | |
| Last 10 min | Offload + log | Offload + log | Offload + log |

### Next week

| Day | Group 1 | Group 2 | Group 3 |
|-----|---------|---------|---------|
| Mon | | | |
| Tue | | | |
| Wed | | | |

**Fill in the location, not just "filming."** "Hallway by 210" is a schedule. "Filming" is not.

### Conflicts to solve out loud, as a class

- Two groups needing the **same location** at the same time
- Two groups needing the **same person** as a subject
- A group needing a location that is **in use** that period
- Who gets the camera **first** on Thursday, and when it hands off

---

## Part 5: The call sheet

Once the schedule is set, each group writes a **call sheet** for their first shoot. This is the document you
actually carry.

```
CALL SHEET
Group: ____________________     Date: ____________
Location: ____________________  Camera: ___________

WHO IS WHERE, WHEN
  Time      Who          Doing what
  ______    __________   ___________________
  ______    __________   ___________________
  ______    __________   ___________________

SHOTS TO GET (in shooting order)
  [ ] Shot ___  ______________________________
  [ ] Shot ___  ______________________________
  [ ] Shot ___  ______________________________

GEAR
  [ ] Camera + charged battery + spare
  [ ] Card with space
  [ ] Tripod
  [ ] Mic, if using
  [ ] Script + shot list

SETTINGS (everyone in the group matches these)
  Resolution: __________  Frame rate: _______
  Shutter: __________ (double the frame rate)
  White balance preset: __________

BEFORE WE LEAVE
  [ ] Room tone recorded
  [ ] Footage played back and checked
  [ ] Everything offloaded and named
```

## If You Finish Early

1. Write a **backup plan** for your hardest shot. What do you do if that location is locked?
2. List every **person who is not in your group** that you need. Have you asked them yet?
3. Build a second call sheet for your first shoot next week
4. Go back through your shot list and mark which shots are **essential** versus **nice to have**. If you lose
   a session, which ones survive?
