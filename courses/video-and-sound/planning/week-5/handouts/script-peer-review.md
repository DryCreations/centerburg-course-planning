# Script Peer Review

**Video & Sound, Week 5.** You read someone else's script and give them findings they can act on. Then they
do the same for you.

**Work inside your production group.** You are about to shoot together, so you need to know what is in each
other's scripts anyway.

---

## Round 1: Read it out loud

Do not read silently. **Out loud, taking parts**, one person reading action lines.

**The writer does not explain anything and does not join in.** Listen and mark.

Mark every place where:

- The reader **stumbled** or had to reread a line
- You could not tell **who was speaking** or **where you were**
- You had to **ask a question** to keep going

> A stumble is almost never the reader's fault. It is a line that is not written the way people talk.

---

## Round 2: Check the format

| Check | Yes / No |
|-------|----------|
| Scene headings are INT. or EXT., with a location and a time, all caps | |
| The same location uses the **exact same name** every time it appears | |
| Action is in present tense | |
| Character names are all caps on their own line above the dialogue | |
| No camera directions in the script | |
| Parentheticals used almost never | |
| 2 to 3 pages | |

---

## Round 3: Is it filmable?

**Go line by line through the action.** For each one ask: **could a camera record this?**

Circle anything that describes a thought, a feeling, a memory, or a backstory. Those have to become actions.

| If they wrote | Ask them |
|---------------|----------|
| A feeling ("she is nervous") | What does she DO that shows it? |
| A memory or backstory | How would we see this on screen? |
| Something invisible ("he decides to go") | What is the visible moment of deciding? |

---

## Round 4: Can we actually shoot it?

This is the round that matters most this week, because you are about to schedule it.

For every scene, answer:

| Question | Notes |
|----------|-------|
| **Where** does this have to be shot? | |
| Can we **get** to that place during class? | |
| Does it need **people who are not in our group**? | |
| Does it need the location to be **empty**? | |
| Is there anything here we **cannot get**? | |

**Any "no" or "cannot get" is a rewrite, and it is easier to rewrite now than to lose a shoot day to it.**

---

## Round 5: Write your findings

Give the writer three things, in writing. Be specific enough to act on.

**1. The strongest thing in it:**

> ______________________________________________________________________

**2. The line or moment that did not work, and why:**

> ______________________________________________________________________

**3. The shot that is going to be hardest to get, and what you would do about it:**

> ______________________________________________________________________

---

## Reviewer checklist

- [ ] Read out loud, taking parts
- [ ] Format checked against the table
- [ ] Every action line checked for filmability
- [ ] Every scene checked for whether we can actually get there
- [ ] Three written findings handed to the writer

## Writer checklist

- [ ] Listened without explaining
- [ ] Marked every stumble
- [ ] Got three written findings
- [ ] **Changed at least three things** and can name them
