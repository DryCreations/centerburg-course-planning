# Video and Sound — BPA Competition Reference

**Course:** 145110 Video and Sound
**See also:** [Master BPA Events Reference](../../../program/bpa/bpa-events-master.md)

> **Cross-course note:** Students may compete in any BPA event. Events below are the strongest natural fits for Video and Sound content. This course has the most direct 1:1 BPA event alignment in the program — the competition entries **are** the course's production projects.

---

## Competition Pathway

```
School Competition (January)  →  Ohio State Conference (Feb/Mar)  →  NLC Nashville (May 6–10)
Virtual Events: skip qualifying entirely — register Dec 1, submit Jan 15
```

Advancing at each stage is the student's choice. See the [master document](../../../program/bpa/bpa-events-master.md) for full dates and details.

---

## Primary Events for Video and Sound Students

### #430 Video Production Team *(Recommended primary event)*

| | |
|---|---|
| **Format** | Team (up to 3) |
| **Deliverable** | 3–5 minute video production on the assigned WSAP topic |
| **Division** | Secondary and Post-Secondary |
| **BPA Topic** | Assigned theme/topic each year by WSAP |
| **Class Connection** | Unit 2.2 (BPA Project full production — this IS the course project) |
| **BPA vs. Class** | The BPA production IS the course project. Students using the BPA WSAP topic do not create a separate piece. The class deadline and the BPA submission use the same production. |
| **Why it fits** | The strongest direct alignment in the program. Pre-production, principal photography, editing, sound mix, and export are all BPA deliverables and course competencies simultaneously. |

---

### #445 Broadcast News Production Team *(Strong alternate — journalism format)*

| | |
|---|---|
| **Format** | Team (2–3) |
| **Deliverable** | 3–5 min news broadcast with two distinct segments (news stories) |
| **Class Connection** | Unit 2.2 (BPA production block) — teams that want a journalism/broadcast format use this instead of #430 |
| **Notes** | Same production skill set as #430 but structured as a newscast. Good for teams that gravitate toward storytelling with a news journalism angle. Only one primary event per student — teams choose either 430 or 445. |

---

### #450 Podcast Production Team *(Audio track primary)*

| | |
|---|---|
| **Format** | Team (2–3) |
| **Deliverable** | 3–5 minute podcast on the assigned topic |
| **Class Connection** | Unit 1.3 (Audio Production Demo Reel) — the demo reel IS the foundation for this entry |
| **BPA vs. Class** | Class: audio piece demonstrating mic placement, Foley, mixing, time code. BPA: same skills applied to a full podcast format on the WSAP topic. Students using the BPA option begin adapting toward podcast structure during Unit 1.3. |
| **Why it fits** | The audio production unit (7.8) — the highest EOC weight outcome — maps directly to podcast production. This is the only BPA event that rewards pure audio skills. |

---

### #420 Digital Media Production *(Individual or smaller-scope option)*

| | |
|---|---|
| **Format** | Individual or Team (up to 3) |
| **Deliverable** | 1–2 min digital media production on assigned topic |
| **Class Connection** | Any project — more accessible scope than 430. Good for first-year students, solo competitors, or smaller classes. |
| **Notes** | Students who want to compete individually or aren't ready for a 3–5 min production should use this event. Counts as a full competition entry. |

## Team Formation Notes

- All primary events (#430, #445, #450) are team events (2–3 members)
- Form teams **by Week 8** — teams need time to collaborate on pre-production planning
- Teams do not need to be from the same class
- #420 can be individual — good for students who can't find or prefer not to work with a team
- Virtual events (V11, V02) are team; V01, V15 are individual
