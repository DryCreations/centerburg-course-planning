# Splitting a Long File Into Clips

**Video & Sound | Teacher reference** | **Not for students**

Several of the practice projects download as **one long video containing everything.** Students need
separate usable pieces.

> **CapCut has no media-panel subclips.** There is no way to split a file into separate assets in the
> media area. Everything below is the realistic set of options.

---

## Option 1: Split Scenes, inside CapCut

**Right-click the clip, choose Split Scenes.** CapCut detects scene changes and cuts the file at each
one automatically.

| | |
|---|---|
| **Good** | One action instead of fifty. Handles a single long file well |
| **Catch** | The pieces land **on the timeline**, not in the media panel |
| **Unverified** | **Test this on one file before class.** CapCut's desktop builds differ by version and platform, and this could not be confirmed from here |

**This is probably the answer** if the goal is just getting a long file into workable chunks quickly.

---

## Option 2: Split on the timeline, normally

Drag the whole clip down, position the playhead, Split, repeat.

**This is the normal professional workflow and it is worth saying so.** Subclips are an optimization,
not a prerequisite. Most editors pull a long clip onto the timeline and cut it there.

**The objection to it is reasonable** (a cluttered timeline is harder to think in), but it is not wrong
and it costs nothing to set up.

---

## Option 3: Pre-split outside CapCut

If you want genuinely separate files sitting in the media panel.

### LosslessCut (recommended)

Free, open source, runs on macOS. **Built for exactly this job.**

Scrub, mark in and out, export the segment, repeat. **Lossless and near-instant**, because it does not
re-encode.

**Workflow:** you split the file once into named clips, drop them in the shared folder, and every
student imports clean assets. **Students never deal with it.**

### QuickTime Player

Already installed. **Edit > Trim**, then **File > Export As**.

Works, but one segment at a time, and it re-encodes. Fine for five clips, painful for twenty.

---

## What I would actually do

**Pre-split once, yourself, with LosslessCut**, and hand out a folder of named clips.

Reasons:

- **It is the student experience you wanted**: drag and drop named assets
- **You do it once.** Thirty students doing it thirty times is thirty chances to do it wrong
- **The naming becomes yours**, so logs and conversations reference the same words
- It removes a technical obstacle from a week whose content is **editing decisions**, not file management

**If time does not allow:** use Split Scenes, or just let them split on the timeline. Neither harms the
lesson.

---

## This does not block Thursday

**Logging timestamps is a document task.** Students watch, write down where each shot starts and ends,
and mark the script.

**That work is the same regardless of how the file eventually gets split**, and it is arguably more
valuable with one long file, because the timestamps are then genuinely load-bearing.

**You only need this resolved by Tuesday**, when the first storyboards clear the gate and editing
starts.
