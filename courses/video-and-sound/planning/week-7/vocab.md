## How to actually study this

Reading the list does not work. **Do this instead**, it takes fifteen minutes:

1. **Cover the right column.** Read a term, say the definition out loud, then check
2. **Mark the ones you missed.** Only those
3. Do the marked ones again
4. Then go the **other direction**: cover the left column, read the definition, name the term. Harder,
   and it is the direction the quiz sometimes asks

> **If you can only recognize a word when you see it next to its definition, you do not know it yet.**
> That is the trap with vocabulary lists, and it is why people who "studied" still miss questions.

## Pre-production

| Term | Meaning |
|---|---|
| **Script** | The written version: what is said and what happens |
| **Storyboard** | Drawings of what each shot will look like |
| **Shot list** | Every shot to be captured, in the order you will shoot them |
| **Production schedule** | When and where each thing gets shot, grouped by location and setup rather than story order |
| **Call sheet** | Who needs to be where, and when |
| **Pre-production** | Everything before the camera rolls |
| **Production** | Shooting |
| **Post-production** | Editing and everything after |

## Shots and framing

| Term | Meaning |
|---|---|
| **Establishing shot** | Wide shot showing where you are |
| **Wide shot** | Subject and surroundings |
| **Medium shot** | Roughly waist up |
| **Medium close-up** | Roughly chest up |
| **Close-up** | Face, or a detail filling the frame |
| **Extreme close-up** | A single detail: eyes, hands, an object |
| **Over the shoulder** | Framed past one person's shoulder onto another |
| **Two shot** | Two people in frame |
| **Insert** | A close detail shot cut into a scene |
| **Headroom** | Space above the subject's head |
| **Lead room / looking room** | Space in front of where someone looks or moves |
| **Rule of thirds** | Placing the subject on a third line rather than dead center |
| **Coverage** | How many different shots you have of the same moment |

## Camera

| Term | Meaning |
|---|---|
| **Frame rate** | Frames per second. We shoot 30 |
| **Shutter speed** | How long each frame is exposed |
| **180 degree rule (shutter)** | Shutter speed should be about **double the frame rate**. 1/60 at 30fps |
| **180 degree rule (camera placement)** | Keep the camera on one side of an imaginary line so screen direction does not flip. **Different rule, same name** |
| **Aperture** | How wide the lens opens. Affects brightness and depth of field |
| **ISO** | Sensor sensitivity. Higher is brighter and grainier |
| **Exposure** | Overall brightness of the image |
| **White balance** | Setting so white looks white under that lighting |
| **Depth of field** | How much is in focus front to back |
| **Manual mode** | You set exposure, and it does not change shot to shot |

## Editing

| Term | Meaning |
|---|---|
| **Timeline** | The left to right strip that is your edit |
| **Playhead** | The line marking where you are in time |
| **Clip** | One piece of footage on the timeline |
| **Media pool / bin** | Imported footage, before it is in the edit |
| **Trim** | Shortening a clip by moving its start or end |
| **In point / out point** | The frame a clip starts and ends on |
| **Handles** | Extra footage kept past the in and out points |
| **Split** | Cutting one clip into two |
| **Cut** | Going straight from one shot to the next |
| **Assembly / rough cut** | Clips in order, roughly trimmed |
| **Fine cut** | The pass that tightens timing and fixes bad cuts |
| **Final cut** | The version you deliver |
| **Pacing** | How long shots are held, and how that makes it feel |
| **Jump cut** | Two similar shots cut together so the subject appears to jump |
| **Match cut** | A cut between shots sharing shape or movement, reading as continuous |
| **Cutaway** | A shot inserted over a cut, often to hide it |
| **B-roll** | Supporting footage that is not the main action |
| **J-cut** | The next shot's audio starts before its picture |
| **L-cut** | The previous shot's audio continues after its picture ends |
| **Dissolve** | One shot blending into the next |
| **Fade** | Gradual change to or from black |
| **Non-linear editing** | You can change any part at any time without redoing the rest |
| **Timecode** | The hours, minutes, seconds, frames address of a point |
| **Render / export** | Turning the timeline into a finished video file |

## Titles and graphics

| Term | Meaning |
|---|---|
| **Title card** | Full screen text, usually the name of the piece |
| **Lower third** | A text label in the bottom of frame naming a person or place |
| **Credits** | Who did what, at the end |

## Color

| Term | Meaning |
|---|---|
| **Color correction** | Making it look **right**: shots match, white is white |
| **Color grading** | Making it look **like something**: a mood or style |
| **Contrast** | How far apart the darks and lights are |
| **Saturation** | How intense the colors are |
| **Temperature** | How warm (orange) or cool (blue) the image reads |

## Audio

| Term | Meaning |
|---|---|
| **Levels** | How loud audio is. Matching levels stops jumps at cuts |
| **Room tone** | The natural background sound of a location, recorded on purpose |
| **Sync** | Audio lined up with the picture it belongs to |
| **Mixing** | Balancing all the audio so everything sits where it should |

## Technical

| Term | Meaning |
|---|---|
| **Resolution** | Frame size in pixels. We export 1920x1080 |
| **Aspect ratio** | The shape of the frame. 16:9 |
| **1080p** | 1920x1080 |
| **Offload** | Copying footage from the card to a folder before editing |

## The five most-confused pairs

These are where the quiz will catch you.

| | |
|---|---|
| **Jump cut vs. match cut** | Jump cut is a mistake, match cut is on purpose |
| **The two 180 degree rules** | One is shutter speed, one is camera placement. Unrelated |
| **Correction vs. grading** | Right, versus a look |
| **J-cut vs. L-cut** | J: next shot's sound comes early. L: last shot's sound lingers |
| **Frame rate vs. shutter speed** | Frames per second, versus how long each one is exposed |
