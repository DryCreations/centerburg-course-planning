## Week 29 — Test Week

### ⚑ WebXam Initial Test — Administered by April 23

**Before the test:**
- [ ] Scored practice quiz (15 questions from this unit)
- [ ] Completed strand deep dives for 2 priority strands
- [ ] Missed question analysis complete (3 questions)
- [ ] Reviewed all vocab cards for Units 1.1–3.3

**Day of test (class procedure):**
1. Arrive on time, bring only what the teacher allows
2. Use the self-comparison table to remind yourself of your goals
3. Pacing: aim to answer all questions; flag uncertain ones for review
4. Review flagged questions if time allows

**After the test:**
- [ ] Makeups scheduled (if absent on test day — same week)
- [ ] Preliminary strand results retained for Unit 4.2 remediation plan
