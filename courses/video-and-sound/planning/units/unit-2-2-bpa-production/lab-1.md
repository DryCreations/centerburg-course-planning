# Lab: BPA Project Production Lab

**Course:** Video and Sound (145110)
**Unit:** 2.2 — BPA Project: Proposal & Production
**Duration:** Weeks 13–18 (6 weeks)

---

## Objective

Execute the full production workflow for your BPA project — from proposal presentation through first cut screening. Every deliverable is both a course artifact and a step toward your competition entry.

---

## Week 13 — Project Proposal

### Proposal Document Requirements

Submit a written proposal using the following structure:

| Section | Required Content |
|---------|----------------|
| 1. Project title and BPA event | Event # and name; WSAP topic (from WSAP document) |
| 2. Team roster and roles | Names, primary roles (director, cinematographer, audio, editor) |
| 3. Concept summary | 2–3 sentences: what is the video, who is it for, what will it say |
| 4. Script or storyboard summary | Describe or attach the pre-production package from Unit 1.2 |
| 5. Shot list | At minimum, 10 planned shots |
| 6. Production schedule | Week-by-week breakdown (Wks 14–17) |
| 7. Equipment list | Cameras, mics, lights needed; note any special requests |

Present the proposal to the class (5 minutes). Receive peer feedback.

## Extension Task

Based on peer feedback, write a revision plan: list the top 3 changes you will make before the final cut, the reason for each change, and the specific timeline (which editing session you will complete each in). Then implement at least 1 change and push an updated export before the end of Week 18.
