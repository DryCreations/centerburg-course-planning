# Lab: Audio Production Fundamentals — Mic Techniques & Multi-Track Mix

**Course:** Video and Sound (145110)
**Unit:** 1.3 — Audio Production Fundamentals
**Duration:** Weeks 5–7 (3 weeks)

---

## Objective

Demonstrate professional audio recording technique through three hands-on exercises: microphone placement comparison, Foley recording, and a multi-track mix session. The completed mix becomes the foundation of the Unit 1.3 project.

---

## Lab A — Microphone Placement Comparison (Week 5)

### Setup

Working with your production team (or individually), select one audio source (a classmate speaking a 30-second script, a musical instrument, or a sound-making prop).

### Procedure

Record the same source 3 times, changing only the microphone placement:

| Take | Mic Type | Polar Pattern | Distance From Source | Angle | Notes on Resulting Sound |
|------|---------|--------------|----------------------|-------|--------------------------|
| 1 | | Cardioid | 3–4 inches | On-axis (direct front) | |
| 2 | | Cardioid | 2 feet | Slightly off-axis (side) | |
| 3 | | Cardioid or dynamic | 1 foot + angle | 45° off-axis | |

After recording, listen back to all three takes and write a brief analysis (2–3 sentences per take):
- Which take sounds most professional? Why?
- Which take would you use for a podcast? For a documentary interview?

## Lab C — Multi-Track Session (Week 7)

### Procedure

In the DAW, build a minimum 4-track audio session using:
- Track 1: Narration or dialogue (your own voice, 30–60 seconds)
- Track 2: Music bed (royalty-free or Creative Commons — cite your source)
- Track 3: At least 1 Foley/SFX element
- Track 4: Room tone or ambient layer

### Mix Parameters

| Track | Final Relative Volume | EQ Applied? | Notes |
|-------|-----------------------|-------------|-------|
| Narration | | | Should sit on top |
| Music bed | | | Should sit under narration |
| Foley/SFX | | | Timed to moment |
| Ambient | | | Subtle; fills space |

Document your signal chain for the narration track:

**Microphone → ________________ → ________________ → DAW track**

Export the finished mix as a .wav or .mp3 file.
