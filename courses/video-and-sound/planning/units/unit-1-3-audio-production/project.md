# Project: Audio Production Demo Reel

**Course:** Video and Sound (145110)
**Unit:** 1.3 — Audio Production Fundamentals
**Weeks:** 5–7

---

## Overview

Produce a 2–3 minute audio piece demonstrating professional technique across the full audio production workflow: microphone placement, Foley effects, multi-track mixing, and time code synchronization.

---

## Class Prompt: Audio Demo Reel

### What You're Producing

A finished, mixed audio piece (2–3 minutes) — your choice of format:
- Podcast segment (information, interview, or storytelling)
- Original soundscape (narrative audio — environment + sound effects + optional narration)
- Radio-style commercial or public service announcement

All formats require the same technical elements.

### Technical Requirements

| Element | Requirement |
|---------|------------|
| Length | 2–3 minutes |
| Microphone | At least 1 close-mic vocal or narration track using correct placement technique |
| Foley / SFX | Minimum 2 original Foley elements or sound effects |
| Music bed | 1 royalty-free or Creative Commons track; cited |
| Multi-track | DAW project with minimum 4 tracks |
| EQ | At least 1 EQ adjustment documented |
| Time code sync | At least 1 element precisely placed using time markers |
| Production notes | 1-page document (submitted alongside the audio file) |

### Production Notes Document

Document:
- Format chosen and why
- Microphone type(s) and placement decisions
- Foley elements — what they are and how they were created
- Music source citation
- One challenge you solved during mixing

## Standards & Rubric

Walk the room as students work. Ask students to point to evidence for each standard before scoring.

| Standard | Description | Look-For (Proficient = 3) | Beginning (1) | Developing (2) | Proficient (3) | Advanced (4) |
|----------|-------------|--------------------------|---------------|----------------|----------------|--------------|
| **7.8.1** | Microphone technique | Mic placement documented in production notes | No documentation | Mic type noted | Placement + direction/distance documented | Placement + pattern selection rationale |
| **7.8.2** | Signal chain / gain staging | Signal chain documented (source → preamp → DAW) | Not documented | Partial chain (2 steps) | Full signal chain documented | Signal chain + gain staging levels at each step |
| **7.8.3** | DAW operation | Full DAW session file with labeled tracks submitted | No session file | Session present; tracks unlabeled | Session + labeled tracks submitted | Session + labeled tracks + marker regions per segment |
| **7.8.4** | Multi-track mixing | 4+ tracks mixed with fader levels documented | 1–2 tracks | 3 tracks | 4+ tracks with documented fader levels | 4+ tracks + automation note or volume envelope used |
| **7.8.5** | EQ | EQ applied to at least 1 track; described (cut or boost) | No EQ | EQ applied; not described | EQ applied + 1 cut or boost described | EQ applied to 2+ tracks + before/after described |
| **7.8.6** | Foley | 2+ Foley elements present and labeled in session | No Foley | 1 element | 2+ elements labeled in session | 2+ elements + source note (recorded or library) |
| **7.8.7** | Room tone | Ambient layer present in mix | No ambient | Ambient present but unlabeled | Ambient/room tone track labeled and present | Room tone + note on when and how it was recorded |
| **7.8.8** | Noise reduction | Noise reduction applied where needed; documented | Not applied | Applied to 1 track; undocumented | Applied + described in production notes | Applied + before/after audio clip comparison |
| **2.10.5** | Time code / sync | Elements placed at correct time markers | Unsynced | Some elements synced | All elements at correct time markers | All synced + time code log showing source → edit mapping |
