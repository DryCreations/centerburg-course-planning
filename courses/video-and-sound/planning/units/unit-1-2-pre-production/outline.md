## Student Overview

### What Is This Unit About?

Nothing gets shot without a plan. This unit covers the documents that professionals create before a camera is ever turned on: the script in industry-standard format, a storyboard that translates the script into visual shots, and a complete production package (call sheet, shot list, location notes). You will produce all three for a 2–3 minute short video.

### What You'll Be Able to Do

By the end of this unit you will be able to:

- Write a 2–3 page script in industry-standard screenplay format using correct scene headings, action lines, and dialogue
- Create a 12–16 panel storyboard matching the script, annotated with camera angle and shot type for each panel
- Assemble a production package including call sheet, equipment list, location plan, and production schedule

### Common Issues & Responses

- **Scene headings are wrong:** INT./EXT. — LOCATION — DAY/NIGHT — no exceptions. Check all headings in lab before project.
- **Storyboard panels have no annotation:** Camera angle and shot type are REQUIRED on every panel. Blank panels don't count toward the 12 minimum.
- **Call sheet is incomplete:** All 5 sections (location, equipment, talent/crew, schedule, contingency) must be filled in.

### Differentiation Notes

- **Students who need more support:** Provide a 4-page formatted screenplay template with labels.
- **Students who finish early:** Extension in project.md — create a locations scouting photo report (3+ location options with pros/cons).

### Assessment Notes

- Project uses the 1–4 look-for rubric. Key rubric focus: Is the script actually in industry format? Does the storyboard cover the full script? Is the call sheet complete enough that someone could run the shoot without asking you?
