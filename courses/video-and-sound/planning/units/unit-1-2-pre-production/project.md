# Project: Pre-Production Package

**Course:** Video and Sound (145110)
**Unit:** 1.2 — Pre-Production: Scripts, Storyboards & Planning
**Weeks:** 3–4

---

## Overview

Produce a complete pre-production package for a 60-second concept video. Every planning document must be finished before any camera rolls. Present to classmates for structured stakeholder feedback.

---

## Class Prompt: 60-Second Concept Video Package

### What You're Producing

A full pre-production package: logline, two-column script, storyboard, shot list, equipment list, and production schedule — plus documented stakeholder feedback from your class presentation.

### Requirements

| Component | Minimum Requirement |
|-----------|-------------------|
| Logline | 1–2 sentences — topic, purpose, audience |
| Two-column script | Complete for full 60 seconds; time markers every 15 sec |
| Storyboard | 8+ panels with shot types and camera movements labeled |
| Shot list | 8+ shots with type, angle, subject, location, audio note |
| Equipment list | All physical gear needed to execute the plan |
| Production schedule | Realistic day-by-day tasks |
| Feedback table | 2+ pieces of stakeholder feedback; response column complete |

---

## Standards & Rubric

Walk the room as students work. Ask students to point to evidence for each standard before scoring.

| Standard | Description | Look-For (Proficient = 3) | Beginning (1) | Developing (2) | Proficient (3) | Advanced (4) |
|----------|-------------|--------------------------|---------------|----------------|----------------|--------------|
| **7.2.4** | Script | Two-column script with full 60-second dialogue/narration | Outline only | Script present; not two-column | Two-column script, 60 seconds | Two-column + scene headings + audio cues |
| **7.2.5** | Storyboard | 8+ panels with shot type and action description per panel | 1–3 panels | 4–7 panels | 8+ panels with shot type and action | 8+ panels + timing note and camera move per panel |
| **7.2.7** | Shot list | 8+ shots with angle, subject, and action | 1–3 shots | 4–7 shots | 8+ shots with angle, subject, action | 8+ shots + equipment and location per shot |
| **7.2.8** | Equipment / budget | Equipment list with gear needed for the shoot | No list | Partial list (1–2 items) | Full equipment list | Equipment list + availability confirmed + cost estimate |
| **7.2.9** | Production schedule | Day-by-day task breakdown through production | No schedule | Single due date only | Day-by-day schedule with tasks | Schedule + owner assignment per task |
| **7.2.10** | Equipment specifications | Gear listed with camera and audio setup notes | No specifications | Equipment named only | Specs: camera, lens, mic noted | Specs + settings targets (aperture, ISO range, audio levels) |
| **7.2.11** | Location / release consideration | Location identified with release or access note | No location noted | Location named; no access note | Location + release/access consideration noted | Location + scouting note + release form or plan |
| **7.3.1** | A-roll / B-roll planning | Shot list distinguishes A-roll (primary) and B-roll (cover) | No distinction | Some shots labeled | All shots labeled A or B-roll | Labeled + B-roll coverage list for each A-roll moment |
| **2.9.1** | Stakeholder feedback | Presentation done; written feedback documented | Not presented | Presented; no feedback | Presentation + feedback table complete | Presentation + feedback + documented revision response |

## Extension Task

After receiving feedback, revise the script to incorporate at least one meaningful change. Submit original and revised script with a revision note (3–5 sentences explaining what changed, what feedback prompted it, and what effect the change will have on the final video).
