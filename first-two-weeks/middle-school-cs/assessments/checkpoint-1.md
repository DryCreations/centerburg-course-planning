## Multiple Choice

**1.** A sprite's **velocity** controls:

A. What color it is
B. How fast it moves and which way
C. How many points it is worth
D. Whether the game is over

**2.** You set a sprite's velocity to vx = 40, vy = 0. The sprite:

A. Moves up
B. Moves down
C. Moves to the right
D. Does not move

**3.** A **variable** is:

A. A picture in your game
B. A named box that holds a value
C. Code that repeats
D. Something that went wrong

**4.** The best place to add a point when the player catches a coin is:

A. Inside a forever loop
B. Inside the on-overlap event for the player and the coin
C. On start
D. In a comment

**5.** Which one **decides**, rather than repeats?

A. A loop
B. A sprite
C. A conditional
D. An event

**6.** Your score goes up forever without stopping. The most likely cause is:

A. The sprite is too fast
B. The score change is inside a forever loop
C. The variable was named wrong
D. The game is too short

**7.** You want the game to end when lives reach 0. You would use:

A. A loop
B. A conditional: if lives <= 0, game over
C. A new sprite
D. A faster velocity

**8.** When something is broken and you are trying to fix it, the best approach is to:

A. Change several things at once so you fix it faster
B. Start over from scratch
C. Change one thing, test it, and write down what happened
D. Ask someone else to fix it

## Explain It

**9.** In your own words, what is the difference between a **loop** and a **conditional**? Give an example of
when you would use each in a game.

**10.** Describe one bug you hit while building your game, and the one thing you changed to fix it.
