## Multiple Choice

**1.** Which part of a computer does the thinking?

A. RAM
B. CPU
C. Storage
D. GPU

**2.** You are working on a document and the power goes out. Your unsaved work is gone. Why?

A. The file was corrupted
B. Unsaved work lives in memory, and memory is wiped when the power goes off
C. Storage is too slow
D. The CPU deleted it

**3.** Which is the best comparison?

A. RAM is the filing cabinet, storage is the desk
B. RAM is the desk, storage is the filing cabinet
C. RAM and storage are the same thing
D. Storage does the thinking, RAM draws the screen

**4.** A variable is:

A. Code that repeats
B. A named box that holds a value
C. A picture in your game
D. Something that went wrong

**5.** Which one decides, rather than repeats?

A. A loop
B. A conditional
C. A sprite
D. An event

**6.** Your score keeps going up forever without stopping. The most likely cause is:

A. The sprite is too fast
B. The score change is inside a forever loop
C. The variable was named wrong
D. The game is too short

**7.** When something is broken and you are trying to fix it, the best approach is to:

A. Change several things at once so you fix it faster
B. Start over from scratch
C. Change one thing, test it, and write down what happened
D. Ask someone else to fix it

**8.** Your digital footprint is:

A. Only the things you post
B. Everything you post and everything posted about you
C. Only what is on your school account
D. Deleted when you delete a post
