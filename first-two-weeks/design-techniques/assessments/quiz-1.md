## Multiple Choice

**1.** A photo is enlarged to four times its original size and turns blocky and soft. This happens because a
photo is:

A. a vector image
B. a raster image
C. a CMYK file
D. exported incorrectly

**2.** You are designing something that will be printed. Which color mode should the file use?

A. RGB
B. Hex
C. CMYK
D. PNG

**3.** Which file should you export a logo as if it needs to sit on top of a colored background with no white
box around it?

A. JPG
B. PDF
C. PNG with a transparent background
D. RGB

**4.** What is a brand kit?

A. A folder of finished projects
B. A saved set of colors, fonts, and logos reused so everything matches
C. The list of requirements for an assignment
D. A collection of stock photos

**5.** Why do designers specify colors with a hex code instead of a color name?

A. Hex codes make files smaller
B. Color names are not allowed in Adobe Express
C. A hex code is one exact color, and a name like "blue" is not a specification
D. Hex codes print faster

**6.** Three moves control what a viewer looks at first. They are:

A. Color, texture, and shape
B. Size, contrast, and position
C. Serif, sans serif, and script
D. Raster, vector, and PDF

**7.** A typeface with small feet on the ends of the letters is called:

A. Sans serif
B. Serif
C. Monospace
D. Display

**8.** Your monogram looks great at full size but turns into a smudge at thumbnail size. The fix is to:

A. Export it as a JPG
B. Raise the resolution
C. Simplify it to fewer shapes
D. Change the color

**9.** What does "meets the brief" mean on the project rubric?

A. The work is finished early
B. The work does everything the assignment asked it to do
C. The work looks professional
D. The work is under the file size limit

**10.** Your file name should look like:

A. `final_FINAL_v2.png`
B. `Untitled design (3).png`
C. `lastname-monogram-v1.png`
D. `my monogram.png`

## Short Answer

**11.** In two sentences, explain the difference between raster and vector, and give one example of when you
would use each.

**12.** You built a poster and nobody can tell what the most important information is. Name two specific
changes you would make and say what each one does.

---

## Answer Key

1: B, 2: C, 3: C, 4: B, 5: C, 6: B, 7: B, 8: C, 9: B, 10: C

**11.** Full credit needs both definitions right, raster is pixels and vector is math or shapes, plus one
correct use for each. Photos are raster, logos should be vector.

**12.** Full credit needs two of size, contrast, or position, each with a reason attached. "Make it bigger" on
its own is half credit. "Make the headline bigger so it is the first thing read" is full credit.
