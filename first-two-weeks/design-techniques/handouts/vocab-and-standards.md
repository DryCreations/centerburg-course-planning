### Words to Know

| Word | What it means |
|------|---------------|
| Canvas | The size and shape of the file you design in, set before you start. Ours is 2560 by 2560 pixels. |
| Resolution | How many pixels are in the image. Too few and it looks soft in print. |
| Export | Saving a finished copy in a format someone else can open, like PNG or PDF. The project file is not the deliverable. |
| Composition | Where things sit in the frame and how that guides the eye. |
| Contrast | The difference between two things, usually light and dark, that makes one stand out. |
| Alignment | Edges lining up with each other on purpose instead of by accident. |
| Naming convention | The agreed pattern for file names. Ours is lastname-item-version.ext. |
| Brief | The list of what the work has to do. Meeting the brief comes before making it pretty. |

### Words to Know

| Word | What it means |
|------|---------------|
| Brand kit | A saved set of colors, fonts, and logos you reuse so everything matches. |
| Hex code | The six character code for an exact color, like #1F4E79. "Blue" is not a specification. |
| RGB | Color made of red, green, and blue light. Used for anything on a screen. |
| CMYK | Color made of cyan, magenta, yellow, and black ink. Used for print. Bright screen colors get duller here. |
| Raster | An image made of pixels. Photos are raster. It breaks down when you enlarge it. |
| Vector | An image made of math and shapes. It stays sharp at any size. Logos should be vector. |
| Typeface | The design of the letters, like Helvetica. A font is one weight or style of it. |
| Serif and sans serif | Serif has small feet on the letters. Sans serif does not. |
| Hierarchy | The order you notice things in. You control it with size, contrast, and position. |
| Visual weight | How much a thing pulls your eye, based on size, color, and darkness. |
| Transparent background | A PNG export with no white box behind it, so the mark can sit on anything. |
| Monogram | A mark built from initials. |

## This Week's Standards, Full Text

Four competencies, word for word from the Ohio CTE standards. The exam uses this language, so read them once
even though they do not sound like the way anyone talks.

**7.4.5.** Differentiate between vector and raster images.

**7.4.7.** Optimize and export graphics files for intended use.

**7.5.2.** Mix families of type within a project.

**7.4.2.** Select color, shape, size, and texture of objects.

Everything you do this week is one of those four. The brand kit is 7.4.2 and 7.5.2. The export test is 7.4.5
and 7.4.7. The monogram is all four at once.
