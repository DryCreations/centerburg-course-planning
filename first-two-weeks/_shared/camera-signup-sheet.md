# Camera Signup Sheet

One sheet for the whole room, same as the checkout form. Students claim a camera ahead of time so the gear is
spoken for before the period starts instead of being fought over in the first five minutes.

This is different from the checkout form. The signup sheet is the reservation. The checkout form is the record
of the camera actually leaving the cabinet. Both happen.

---

## Build It as a Google Sheet

One tab per week. Share with the four courses as "anyone with the link can edit," post the link in every
Classroom, and pin it.

**Row 1, paste these headers across:**

```
Date	Period / Class	Camera ID	Student Name	What You Are Shooting	Out	Back	Notes
```

Pre-fill the Date, Period, and Camera ID columns for the next two weeks so students only fill in the four
columns that are theirs. An empty grid gets ignored. A grid with their period already on it gets used.

**Example rows, filled in so they can see what it should look like:**

```
Aug 26	4th, Yearbook	CAM-02	Ruiz, Elena	Volleyball practice, gym	x	x	need the 55-250 lens
Aug 26	5th, Video	CAM-01	Vail, Marcus	Camera modes lab, room + hallway	x		
Aug 27	After school	CAM-03	Ruiz, Elena	Home volleyball, 6pm	x		taking it overnight, back 8th period Thu
```

---

## Rules, Post These at the Top of the Sheet

1. One camera per person per slot. If you need it two periods in a row, take two rows.
2. Sign up at least the day before for in class work, and at least two days before for an event.
3. Overnight and event checkouts need my name on the row before you take it.
4. If your plan changes, delete your name. An unused reservation costs somebody else a shoot.
5. Signing up is not checking out. You still fill out the checkout form and I still confirm the return.
6. A camera comes back with the card offloaded, the card cleared, and the battery on the charger. Every time.

---

## Priority When Two People Want the Same Camera

Say this once so nobody thinks it is arbitrary.

1. A scheduled event with a deadline attached.
2. Coverage for a beat that nobody else can shoot.
3. A graded assignment due that week.
4. Practice and personal work.

Yearbook events beat class labs, because the game only happens once and the lab can run tomorrow.

---

## Teacher Column

Add a hidden or far right column for yourself: **Confirmed Back**. Fill it in when the case comes back
complete. That column is the whole record if a camera goes missing, and it is the list you use to decide who
gets independent checkout later in the year.
